# 社会学的思维方式 · Thinking as Sociologists

> 一套可以照着走的社会学看法：先把「本来就这样」变成问题，再把问题拆成机制，最后算清谁在付账。

社会学的门槛不在"读没读过经典"，而在**看东西的顺序**：先问这件事发生在哪一层，再问它靠什么机制运转，最后问它让谁受益、让谁承担代价。顺序对了，普通人也看得出门道；顺序错了，读再多理论也只是换词。

这个技能把它拆成可执行的动作、可查的概念表、可复用的案例库与一整套中国场景的制度分析。

## 它覆盖四类场景

| 场景 | 用户说的话 | 交付什么 |
|---|---|---|
| **知识科普** | "什么是社会建构""社会学到底研究什么" | 反常识切入 → 一句人话定义 → 判别标志 → 常见误读 |
| **现象解读** | "为什么考公这么热""怎么看待这条新闻" | 三层定位 → 机制三环 → 谁受益谁付账 → 反例与边界 |
| **专业答疑** | "功能论和冲突论差在哪""个案能不能外推" | 定义 → 判据 → 分歧根源 → 什么证据能分开两边 |
| **学习辅导** | "带我学社会学""理论怎么串""方法怎么选" | 知识地图 → 学习路径 → 每站一个自测题 |

## 三条硬规则

1. **先定层，再解释。** 微观（互动）、中观（组织）、宏观（制度）三层不分，所有解释都会各说各话。
2. **解释必须落到机制。** 说得出"谁在什么位置、被什么考核、面对什么代价、于是做了什么"。说不出，就还是印象。
3. **中国场景先做"概念折价"。** 西方概念带着制度前提（国家与社会边界清晰、正式规则可执行、个体是分析单位）。缺哪条，就说明用什么替代机制补上，再使用。

## 怎么装

把整个目录放进技能目录即可：

```
~/.workbuddy/skills/sociology-thinking/
```

或解压发布包到同一位置。技能会在遇到社会学概念、社会现象解读、理论与方法问题时自动触发。

## 适合谁

- 想用社会学解释身边事的写作者、内容创作者、教师
- 需要给学生讲清概念的社会学入门课
- 做中国治理、城乡、基层议题的经验研究者（当作机制清单用）
- 对"为什么大家都这样"这类问题真的好奇的人

## 不适合

- 心理咨询与人格测评
- 经济预测与投资建议
- 党派政治评论
- 文学艺术批评

## 一句话

**社会学不承诺让你过得更好，它承诺让你知道自己站在哪。**
