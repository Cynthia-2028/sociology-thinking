# 10 基层治理与社会秩序

这一份回答一类问题：**为什么基层"责任无限、权力有限"？为什么按文件办常常办不成，而"做工作"成本那么高却仍被选择？秩序到底靠什么维持？**

---

## 一、条块结合：一件事为什么会有两个"婆婆"

- **条条**：职能部门的纵向系统（业务指导、标准、考核）。
- **块块**：属地政府的横向统合（人事、财政、协调）。
- **以块为主**：人、钱、事最终落在属地。

**识别办法三招**（不用查文件）：
1. 看机构全称里有没有上级前缀；
2. 看一把手由谁任免；
3. 看经费由谁拨。

称呼上也藏着权力：**"领导"**（可任免、可考核）与**"指导"**（只能协调）是两种关系。

**为什么推诿几乎必然发生**：把一件事拆成五个环节——**认定、决策、出资、执行、执法**——多数推诿发生在环节之间，而不是环节之内。每个环节归属不同，责任就在缝里消失。

**判据**：能事先指出这件事会卡在哪一环、卡住后由谁背锅，而不是事后归因于"干部能力"。

---

## 二、责任赤字：避责为什么是理性的

**责任赤字 = 责任清单 − 权力清单**（审批、执法、财政、人事四项逐项打勾）。

赤字越大，越依赖上级资源与临时授权；赤字大到一定程度，**优先降低被问责概率**而非解决问题，就是理性选择。

**避责的四种典型动作**：
| 动作 | 表现 | 功能 |
|---|---|---|
| 转发 | 层层转发文件，不落地 | 证明"我传达了" |
| 留痕 | 拍照、建群、打卡、台账 | 证明"我做了" |
| 上报 | 事事请示，等指示 | 转移决策责任 |
| 扩大会议 | 人人到场，无人负责 | 分散责任 |

**注意**：避责会把小事拖成舆情，代价最终由群众承担。分析时要两头都说，不能只说"干部不容易"。

**失效条件**：上级给的是"政治任务 + 资源配套 + 临时授权"时（如脱贫攻坚），赤字被短期填平，"军令状"逻辑压过避责逻辑；此时框架只能解释运动结束后的回潮。

## 三、痕迹管理：为什么考核看得见表格、看不见课堂

**机制**：
1. 上级要检查，但结果难测（教学质量、治理成效滞后且多因）；
2. 过程容易测（有没有开会、有没有台账、有没有打卡）；
3. 于是考核重心从"结果"滑向"过程"；
4. 被考核者的理性回应是把工作做成"可被检查的样子"；
5. 上级看到漂亮的痕迹，问题仍在，于是加码检查——循环。

**一个反直觉的结论**：数字化不一定减负。纸质台账变成 App 打卡，是**负担的迁移**，不是减少。技术让考核从结果转向过程，同时生产出"指尖上的形式主义"。

**判据**：能指出"哪张表、哪一级签字"是卡点，而不是笼统说"官僚主义"。

## 四、单位制的遗产：人靠什么被组织

单位制没有消失，它变成了**身份与资格**。

**盘点的五个连接点**：单位、社区、党组织、行业协会、平台站点。一个人身上通常有三到四个。

**三问判性质**：
1. 是**资源依赖**（离开就失去住房、社保、编制）还是**关系依赖**（靠人情维持，随时可断）？
2. **退出成本**有多高？越高越服从，越低越可能"用脚投票"。
3. **分割线**在哪？单位性质（机关、事业、国企、集体）与行政级别如何切割利益、信息与抗风险能力。

**判据**：能解释同一政策在同一城市的不同小区、不同单位为何反响悬殊。

**失效条件**：平台经济下的骑手、灵活就业者没有单位，但不是原子——他们被站点、算法、接单权限"再组织"。此时应把"单位"替换为**平台化依附**。

## 五、信访：一个被设计出来的非常规通道

**它是什么**：科层体系内部设置的、绕过常规程序的救济渠道。功能是**减压阀**，不是病灶。

**双重取向**：同一制度既做冲突化解，也做社会动员。信访量上升，在不同时期被读作"好事"（群众信任）或"警讯"（不稳定）。

**它解决了什么**：常规程序卡住的人（判决已生效、部门互相推诿、属地不受理）有一条非常规出口。
**它生产了什么**：截访成本、牟利型上访、基层"花钱买平安"的激励。

**分析要求**：两头都要认。只说"维稳压制"或只说"刁民闹事"，都是半截。

## 六、人格化联系：为什么"做工作"比"下文"有效

**定义**：治理者以具体的人对具体的人的方式建立联结——因人而异、留缓冲、先谈后罚。

**它不是"人治落后"，是三种条件下的合理选择**：
1. 事项**不可标准化**（拆迁补偿、邻里纠纷、家庭矛盾，一次说不清、后果不可逆）；
2. 关系**可复用**（这次给面子，下次还要找他）；
3. 缺乏**强制执行的现实能力**（真强制会激起更大反弹）。

**人格化与制度化的关系（关键）**：
| | 制度化 | 人格化 |
|---|---|---|
| 强项 | 统一、可预期、可追责 | 灵活、能处理例外、保住关系 |
| 弱项 | 遇到例外就卡死 | 破坏统一标准，引发"会哭的孩子有奶吃" |
| 正确组合 | 程序定底线（红线不能突破） | 人格化做缓冲（底线之上调节奏与方式） |
| 风险 | 僵化、形式主义 | 交易化、攀比、失去公信 |

**判据**：能解释"依法办"为何在具体场景里常常失败，以及为什么干部宁愿花三倍时间做工作，也不愿下一纸告知书。

**失效条件**：涉及重大安全、环保、廉政红线时，人格化空间被压缩为零；当事人已被处理成"抽象反对者"（关系彻底破裂），缓冲失效，只能进入强制程序。

## 七、差序格局、人情与面子：秩序的另一套基础设施

| 概念 | 一句话 | 判别标志 |
|---|---|---|
| 差序格局 | 以己为中心，按亲疏远近配置信任与资源 | 同一规则对不同关系的人宽严不同 |
| 人情 | 以礼物、劳务、宴请为载体的长期互惠账户 | 欠人情要还；不还即断 |
| 面子 | 公开的社会评价与尊严 | 不给面子即断关系；给面子可换配合 |
| 情理 | 讲道理时同时援引"情"与"理" | 只讲法不讲情被视为"不通人情" |

**三个必须说清的判断**：
1. **人情不是腐败**。它是正式保险与法律不足时的替代性互惠机制，也是治理的润滑剂。要区分"人情作为互惠"与"人情侵入公权"，后者靠程序隔离解决。
2. **差序格局不是自私**。在差序格局里公私是相对的：为家牺牲族时，家就是公。缺的不是私德，是超越一切小团体的"团体"。
3. **传统不是断裂，是载体更换**。断的是制度载体（科举、宗族、乡绅），续的是结算方式（情理、面子、关系）。单位可以家族化，法庭调解仍讲"养你一小、你养他一老"。

## 八、抗争：为什么"沉默的大多数"才是常态

**一个反常识的事实**：受损者中多数不行动。行动是**资源密集行为**——要有时间、文化、关系、渠道、讲得出去的道理。

**抗争的形态谱**（从日常到公开）：
1. **日常抵抗**：拖延、装糊涂、变通、找关系、说怪话；
2. **求助式**：找媒体、找上级、找代表、上访；
3. **集体行动**：联名、聚集、诉讼、舆论动员。

**为什么多数人停在第一、二层**：退出成本高、组织成本高、被报复风险高、"说了也没用"的预期强。

**判据**：能解释"为什么同等损失下只有一部分人行动"，差别在有没有人组织、有没有可用的说法、有没有渠道。

**分析要求**：不美化、不煽动、不预测。只做机制描述：什么条件下会行动、什么条件下会沉默、代价由谁承担。

## 九、五个可操作框架

### 框架 A：条块诊断（一件事该谁管）
拆五环节（认定/决策/出资/执行/执法）→ 给每环节标归属（属地/垂直/双重）→ 标考核权（谁打分、谁能一票否决）→ 查块块的实际权力清单（执法权、独立财政、审批权）→ 预测行为（有责无权者上报留痕，有权无责者指导督查）。

### 框架 B：责任—权力匹配检验
列责任清单 → 列权力清单（审批/执法/财政/人事）→ 做差得责任赤字 → 看问责方式（结果问责催生隐瞒，过程问责催生台账）→ 查有无免责与容错条款（没有则"不做事最安全"）。

### 框架 C：痕迹管理诊断
问三件事：结果能不能被独立测量？过程是不是唯一的可核查项？检查者与被检查者之间有没有信息中介？三问下来，痕迹的强度就出来了。

### 框架 D：单位/平台依附盘点
列连接点 → 判资源依赖还是关系依赖 → 算退出成本 → 看分割线 → 预测行动能力（连接弱、退出成本低、又在分割线外的人，最可能既沉默又脆弱）。

### 框架 E：人格化—制度化配比
判事项可标准化程度 → 判关系可复用性 → 看有无缓冲设计（先谈后罚、告知前留期限）→ 找冲突点（人格化破坏统一标准）→ 给组合方案（程序定底线 + 人格化做缓冲 + 留痕做审计）。

## 十、常见误解纠正

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 基层干部不作为就是懒 | 多数"不作为"是责任大于权力时的理性避责 | 先算责任赤字，再谈作风；但避责会把小事拖成舆情，代价由群众承担 |
| 老百姓爱闹 | 抗争是资源密集行为，受损者中多数选择沉默 | 能闹的是少数有资源的人；沉默的大多数才是常态 |
| 中国人只讲关系不讲规则 | 关系常是规则缺位时的替代性执行机制 | 制度化提高后，关系从"打通关节"转向"获取信息与协调"，并未消失 |
| 上访的都是刁民 | 信访是体系内部设计出来的非常规救济通道 | 它确实救济了不少被卡住的人，也确实生产了牟利型上访与截访成本 |
| 运动式治理就是形式主义 | 它是基础能力不足时集中投放资源的唯一办法，常有实效 | 真问题是代价：目标置换、专业被压制；判断标准是有没有转成长效机制 |
| 单位制已经消失 | 单位在收入、住房、社保上的分割作用仍在 | 变的是形式：从"单位办社会"到"单位定身份"，再到"平台定资格" |
| 基层减负就是少填表 | 指标结构与问责方式不变，减负只会换载体 | 从纸质台账变成 App 打卡，是负担的迁移 |
| 数字化能解决基层信息不对称 | 它解决了"看得见"，没解决"愿不愿干" | 技术让考核从结果转向过程，同时生产"指尖上的形式主义" |
| 村民自治就是选举 | 没有财力的自治是空转，选出来的人无从办事 | 自治的经济基础是集体经济；有钱才有议题，有议题才有问责 |
| 维稳就是压制 | 强制是底牌不是常规；日常靠情理、面子与"给个说法" | 用多了情理俱失，反而降低以后的办事能力 |

## 十一、使用边界

1. **只做机制分析，不做立场表态**。可以分析"为什么这项政策在基层会变形"，不评论政策本身该不该有。
2. **不预测具体个案**（谁会被问责、哪件事会发酵）。这类判断涉及多方，任何预测都不负责任。
3. **不美化也不妖魔化**。基层既不是"全能"，也不是"全坏"；描述要能同时解释"为什么有效率"和"为什么会失灵"。
4. **注意时代性**。问责方式、数字化考核、垂直化改革都在变，具体判断要注明基于哪一阶段的机制，并提示以最新政策口径核实。
5. **涉及具体纠纷与维权时，只讲机制与程序，不给法律意见**。需要法律判断的，提示咨询专业渠道。
