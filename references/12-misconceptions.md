# 12 常见误解纠正

用户带着一句"常识判断"来时，先在这里找。三列：**常见说法 / 为什么错（或只对一半）/ 更准确的说法**。
按主题分组，共五十二条。

---

## A 关于社会学本身

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 社会学就是研究社会问题 | 它更常研究"问题如何被定义成问题" | 它追问：谁有权力把某件事叫问题，谁的利益因此被保护 |
| 社会学就是把常识说得复杂 | 常识来自个人位置和有限信息，且倾向把结构问题归因于个人 | 它用系统方法检验常识，专找"常识解释不了的那部分" |
| 社会学就是发问卷、跑统计 | 统计是材料不是学科；没有理论框架的计数不构成解释 | 数字只有被放进"关系与机制"里才成为社会学证据 |
| 社会学应该给出改造方案 | 解释与开方是两种工作；混在一起会让证据迁就结论 | 先能描述与解释，才谈得上负责的方案 |
| 流派太多说明学科不成熟 | 对象高度复杂，没有单一范式能统摄 | 多范式意味着争论多，不等于知识少 |
| 价值中立就是没有立场 | 经典立场只要求取证环节排除偏见 | 该守的是"收集时不歪曲"加"程序可复现" |

## B 结构、个人与责任

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 结构决定一切，个人没得选 | 结构提供概率，不提供命令 | 结构决定"赔率"，行动决定"下注" |
| 讲结构就是替个人开脱 | 结构解释的是概率与分布 | 它不取消责任，只是拒绝把责任全放在个人品性上 |
| 讲系统就是"怪社会" | 系统与人互为条件，非此即彼是假选择 | 要问的是二者如何组合出这个结果 |
| 既然都是社会造成的，我就没责任 | 用解释替换归责；把"概率"误读成"决定" | 位置缩小选择集，但选择仍在 |
| 个人也能改变社会，所以结构不重要 | 改变需要杠杆，意志本身不是杠杆 | 个人通过改变路径与边界来改变系统 |
| 懂社会规律就能预测 | 人的反身性会破坏预测：被预告的预言会改变行为 | 能给的是条件性概率与机制，不是定律 |

## C 文化与社会建构

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 社会建构＝其实不存在 | 建构讲的是意义与后果如何形成，不否认物质性 | 有些事是真的，但"它算什么问题"是人定的 |
| 文化就是读书、看展、听音乐会 | 那是文化的窄义用法 | 文化是符号、信念、价值、规范与态度的总和 |
| 文化不同，所以无法互相理解 | 把差异绝对化，同时否定解释与翻译的可能 | 差异真实，但共同的人类经验足以支撑有限的翻译与比较 |
| 消费是我自己选的 | 选项的清单本身是被提供的 | 选择发生在货架上，货架不在你手里 |
| 只要揭穿了，制度就会改 | 揭穿改变的是可信度，不是利益结构 | 观念松动是先决条件之一，改结构还得改激励与代价 |

## D 分层与流动

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 分层就是收入差距 | 还有声望与权力，且三者常错位 | 三维测量加流动性诊断，才看得见位置的真实形状 |
| 分层是因为有人更聪明更努力 | "重要位置需要奖励"的论证被批评为循环 | 分层既有激励成分，也有封闭与正当化成分 |
| 社会流动越多说明社会越公平 | 结构性流动（产业扩张）能在不公平的结构里制造大量"向上" | 要看相对流动率，而非绝对人数 |
| 寒门难出贵子是因为不努力 | 结构流动与先赋条件解释了大半 | 个人努力的效力，取决于电梯在往哪个方向开 |
| 穷是因为不努力 | 用少数例外解释整体分布 | 位置给出的是概率与容错空间，不是命运 |
| 门当户对是封建残余 | 把它当观念，而它首先是统计事实 | 同类婚配在任何社会都存在，只是筛选语言变了 |
| 中产就是收入在中间的那批人 | 收入中间不等于位置中间 | 还要看职业自主性、资产结构、抗风险能力与身份（编制/户口） |

## E 性别、家庭与教育

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 性别差异是生理决定的 | 同性别的行为跨社会差异巨大 | 性是生物区分，性别是社会配置 |
| 家庭在解体 | 家庭形式在变（单人户、同居、再婚），功能在转移 | 家庭制度在重组，不在退场 |
| 离婚率高是因为人变自私 | 忽略婚姻功能变了：从财产与继承安排变成情感满足安排 | 期望升高 + 女性经济独立 + 寿命延长 + 退出成本下降 |
| 鸡娃是家长虚荣 | 教育分流与择校压力把风险转给家庭 | 个体理性在结构压力下的集体加码 |
| 老师有寒暑假还喊累 | 多任务 + 主业不可测 + 副业可测 | 考核看得见表格、看不见课堂，表格就会赢 |
| 文凭贬值是因为扩招 | 扩招是供给端，贬值取决于需求端与信号结构 | 门槛先动、技能后动；不能"关门"的文凭贬值最快 |

## F 越轨、舆论与惩罚

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 越轨就是坏行为 | 越轨的关键在被认定，不在行为本身 | 同一行为在不同时间、地点、群体被定义的结果不同 |
| 标签论等于替越轨者开脱 | 它解释定义过程，不取消行为责任 | 责任与定义是两个问题，可分开讨论 |
| 网暴是网民素质差 | 命名的权力与放大机制才是主因 | 群体名词代替具体指控，极端个案被当作群体特征 |
| 塌房活该，人设是自己立的 | 观众投入了情感与认同，惩罚带有仪式性 | 惩罚的往往不是错误，是被辜负的信任 |
| 重罚就能治好问题 | 随机重罚传递的是压力，不是规则 | 稳定、可预期的处罚才改变行为 |

## G 组织与治理

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 科层制就是低效 | 理想型的科层制是效率工具，问题在理性化会长出非理性 | 该问"它在压力下先牺牲哪一项" |
| 官僚主义就是人坏 | 是结构产出的行为，换人后模式仍在 | 指出哪个考核、哪项责任、哪种问责造成的 |
| 运动式治理就是形式主义 | 它是基础能力不足时集中投放资源的唯一办法 | 真问题是代价，标准是有没有转成长效机制 |
| 基层不作为就是懒 | 多数是责任大于权力时的理性避责 | 先算责任赤字，再谈作风 |
| 中国人就是爱走关系 | 关系在正式规则不保护人时是替代性保障 | 换制度条件，行为会明显改变 |
| 上访的都是刁民 | 信访是体系内设计的非常规救济通道 | 它救济了被卡住的人，也生产了截访成本 |
| 数字化能解决基层信息不对称 | 它解决"看得见"，没解决"愿不愿干" | 技术让考核从过程化，生产"指尖上的形式主义" |

## H 城乡与乡土

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 农民保守，不愿冒险 | 是风险承受力不同，不是偏好不同 | 保守是"无退路"条件下的理性 |
| 城市化就是让农民进城买房 | 把"人进城"缩成"买房" | 城市化是人与地、人与公共服务同步重组 |
| 土地是农民的，征地给够钱就行 | 关键在允许不允许交易 | 先改权利安排，补偿标准才有意义 |
| 空心村说明农村没救了 | 人走了、房没走、地不能动 | 空心是"流动不同步"的症状 |
| 乡村就是温情脉脉的人情社会 | 熟人社会同时提供支持与压力 | 人情是保障，也是监控 |

## I 方法与证据

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 数据说话就够了 | 数据能显示分布，不能显示机制 | 数据负责排除与校准，机制负责解释 |
| 有相关就有因果 | 缺少时间顺序、机制与竞争解释的排除 | 因果需要三条同时成立 |
| 一个个案不能说明什么 | 个案不推算比例，但能让机制可见 | 关键是写明支撑条件与负向边界 |
| 访谈就是聊天 | 访谈是有提纲、有追问策略、有饱和判断的资料生产 | 没有追问与校验的访谈只是闲聊 |
| 定量比定性科学 | 两者回答不同问题 | 问分布用定量，问机制用定性 |
| 中国特殊，西方理论都不适用 | 只对一半：理论带着制度前提，"不适用"不等于"不可用" | 要做的是"概念折价"——替换判据，而非全盘否定 |
| 西方概念可以直接套 | 会套出假问题 | 先问成立条件，再看缺哪条、用什么替代机制补上 |

## 用法：三步回应

用户说"我觉得××就是××"时：

1. **先承认它抓住了什么**（常识通常抓住了一部分真相，别一上来否定）；
2. **指出它丢掉了什么**（用上表相应行）；
3. **给一个能自己验证的判据**（"你可以去看××，如果……成立，说明我这条解释对"）。

三步下来，用户不是被说服，而是拿到了一个可以自己用的工具。这比赢一场辩论有用。
