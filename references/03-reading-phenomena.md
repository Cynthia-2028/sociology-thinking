# 03 现象解读：拿到一件事，怎么一步步拆开

这份文件是**操作说明书**。用户说"为什么会有××""你怎么看××"时，按这里的流程走，不要凭印象发散。

---

## 第 0 步：先分型（三十秒内完成）

不同类型的现象，入口完全不同。分错型，后面全歪。

| 型 | 特征（用户怎么描述） | 入口 | 主要工具 |
|---|---|---|---|
| **A 分配型** | "为什么他们比我们多/少""凭什么他们能" | 从**位置与规则**入口，不从努力入口 | 三维分层、流动诊断、生活机会 |
| **B 规范型** | "怎么会有人这样""这算不算过分" | 从**谁定义了问题**入口 | 标签论、道德恐慌、污名、建构五步 |
| **C 组织型** | "为什么单位/学校/医院会这样办事" | 从**考核与责任**入口 | 科层病灶、目标置换、避责、条块诊断 |
| **D 意义型** | "为什么大家这么在意××""这有什么意义" | 从**符号与面子**入口 | 拟剧论、消费符号、身份认同、必死性框架 |
| **E 变迁型** | "以前不是这样，现在怎么这样了" | 从**条件变化**入口 | 人口/技术/制度三条线，路径依赖 |

混合型很常见（彩礼 = A + D + E）。**一次只主攻一个型，其余作为背景交代**，否则文章会散。

---

## 五步流程

### 第 1 步：抓「当然句」并改写

把现象里所有人都在重复的那句话拎出来，改写成可检验的命题。

| 原句 | 改写 |
|---|---|
| "现在的年轻人不肯吃苦" | "在什么条件下，某类年轻人会拒绝某类工作" |
| "家长太焦虑了" | "什么制度安排使家长的风险感知持续升高" |
| "基层不作为" | "在什么责任—权力配置下，不作为是理性的" |

**判据**：改写后的句子能让你接着问"哪个社会不这样""哪一代人不这样"。

### 第 2 步：三层定位

```
宏观：制度（户籍/编制/土地/财政）、产业位置、人口结构、政策周期
中观：组织（单位/学校/平台/社区）、考核指标、行业惯例、资源分配
微观：互动（谁在场、说什么、怎么表演）、情绪、面子、日常策略
```

写一句定位声明：「这件事主要发生在中观，但它的边界由宏观划定，落到微观表现为××。」
**这一步只要三行，但必须写。** 不写，后面所有解释都会漂。

### 第 3 步：找机制（核心，占一半篇幅）

按型选链条，链条每一环都要能被证据检验：

**A 分配型**：规则怎么设 → 谁被划进/划出 → 位置给出什么概率 → 人们如何据此调整行动 → 结果如何被说成公平
**B 规范型**：行为发生 → 谁有权力命名 → 命名的时机（为什么是现在）→ 放大机制（媒体/热榜/个案当群体）→ 被标记者如何重组生活
**C 组织型**：任务从哪来 → 责任落在谁头上 → 他手里有什么权与钱 → 考核看什么 → 于是他做什么动作（留痕/上报/推诿/加码）
**D 意义型**：这个东西在什么场合被使用 → 谁在观看 → 表演失败的代价 → 它替换掉了什么旧符号 → 谁靠它区分"我们"和"他们"
**E 变迁型**：旧安排依赖哪些条件 → 哪个条件先变 → 谁先适应 → 适应如何反过来改变激励 → 新均衡卡在哪

**判据**：链条至少三环，且每一环都能回答"你怎么知道"。

### 第 4 步：算账（谁受益、谁付代价、为什么当事人自愿）

三栏必写：
- **省事的人**：谁因此不必解释、不必改动、不必承担；
- **付账的人**：多一道手续、多一层审慎、多一次自证；
- **自愿的机制**：为什么受损者也配合（因为不配合的代价更高，因为退出成本太高，因为这套说法让他自我归因）。

**这一步是本 skill 与"网文式批判"的分界线。** 只骂结构不给自愿机制，读者不信；只讲自愿不谈代价，是 victim blaming。

### 第 5 步：反例与边界

必须给出：
- 一个**同类但结果不同**的案例（同样制度下有人没这么做）；
- 一个**条件变化就会失效**的说明（如果××变了，这套解释就不成立）。

没有反例的解释是宣传，不是分析。

## 输出模板（可直接套用）

```
【一句话判断】
外行会说：……。社会学看到的是：……。

【定位】
这件事在三层同时成立：宏观（……）、中观（……）、微观（……）。

【机制】
第一环……；第二环……；第三环……。

【账】
受益的是……；付账的是……；而当事人之所以配合，是因为……。

【边界】
这套解释在……条件下会失效。反例是……。

【一句话收尾】
（可做标题的短句）
```

篇幅控制：科普向 800–1200 字；解读向 1200–2000 字；专业答疑不套此模板，走"定义—判据—分歧—证据"。

## 六种常见拆错的姿势

| 错法 | 长什么样 | 怎么改 |
|---|---|---|
| **结构决定论** | "这都是社会造成的" | 指出哪个结构、通过谁的什么期待、施加什么代价 |
| **功能辩护** | "它存在总有它的道理" | 补一段"谁付代价"，并区分"为何持续"与"是否应当" |
| **术语替代** | "这就是内卷""资本逻辑而已" | 术语后面必须跟可观察的关系，否则删掉 |
| **道德归因** | "就是人品差/素质低" | 换位置试验：同样的人换个考核，行为会不会变 |
| **单层解释** | 只讲制度不讲互动，或只讲心态不讲制度 | 补上缺失的两层，各写一句 |
| **无量纲结论** | "越来越难了""差距很大" | 给比较对象与量级；没有可靠数字就说"我没有可靠来源" |

## 三个完整的走法（示范）

### 示范一：家长群为什么让人疲惫（D 型 + C 型）

**当然句**："现在家长太爱攀比了。"
**改写**：在什么条件下，家长必须在一个半公开场合持续表演"配合"？

**定位**：宏观——教育分流与择校压力；中观——班级作为考核单元，教师有评价权；微观——群聊是可截图的公开前台。

**机制**：① 群是一个没有落幕的前台，每条发言都被全体观众（家长+老师）观看且可留存；② 表演失败的代价不对称——一次公开质疑被读成"不配合"，而这个印象撤不回来；③ 于是出现标准化的印象管理：感谢公开、质疑私聊、成绩"不经意"提及；④ 真正的抱怨迁到三五人小群（后台）；⑤ 老师也在表演（要显得负责又不能失当），双向表演使群的劳动量持续上升。

**账**：省事的是学校（通知一次到位、责任分散到家长）；付账的是家长的时间与情绪劳动，以及在群里"位置靠后"的家庭；自愿机制是——不配合的孩子可能被区别对待，这个风险家长不敢赌。

**边界**：如果学校明确禁止群内公开评价、或家长之间不存在资源竞争（如小规模村校），这套机制会弱化。

### 示范二：基层为什么热衷"留痕"（C 型）

**当然句**："基层就是形式主义，净搞台账。"
**改写**：在什么责任—权力配置下，留痕比解决问题更划算？

**机制**：① 上级下达任务但不给足资源；② 责任按属地落到末端，权力（执法、财政、审批）多在上级；③ 考核以"可核查"为标准——结果难以核实，过程容易核实；④ 于是理性选择是把工作做成"可被检查的样子"：拍照、建群、填表、打卡；⑤ 上级看到的是漂亮的痕迹，问题仍在，于是下一轮加码检查——循环。

**账**：省事的是中间层级（有据可查、可交差）；付账的是末端的时间与群众的实际体验；自愿机制是"做了没人看见等于没做，没留痕等于没干"。

**边界**：若上级改为数据直采（不经过地方上报）、或结果指标可独立测量，留痕的收益下降，行为会转向真实处置。

### 示范三：彩礼为什么越涨越高（A 型 + D 型 + E 型）

**当然句**："现在的人太物质了。"
**改写**：在什么结构条件下，彩礼会从"礼节"变成"竞价"？

**机制**：① 婚姻市场的地方性失衡（性别比、人口外流）使一部分男性在本地失去议价位置；② 彩礼从"给新婚家庭的启动资金"变成"家庭间的地位信号"——它要能被看见、被比较；③ 面子机制使"低彩礼"不是省钱而是丢脸，于是 downwards 的竞价被堵住；④ 城镇化预期把"县城有房"写进婚姻门槛，彩礼与房价绑在一起；⑤ 女方家庭也常把这笔钱转为嫁妆或新房投入，所以不是单纯的"卖女儿"，而是家庭间的资源再分配与风险对冲。

**账**：受益的是能在本地婚姻市场占位的人与显示地位的家庭；付账的是农村多子家庭与被视为"条件不足"的男性；自愿机制是——不参与竞价的家庭会被排到市场末端。

**边界**：在婚姻市场均衡（性别比平衡、人口流入）或宗族规范强约束彩礼上限的地方，竞价机制不启动。

## 提问脚本（帮用户把模糊问题变清楚）

用户常给一个情绪（"我好累""这社会怎么了"），这时不要直接分析，先用三问定位：

1. **"这件事发生在哪个场合？"**（公司/学校/家里/网上）→ 定中观
2. **"你身边像你这样的人多吗？"** → 判断是私人困扰还是公共议题
3. **"如果不这么做，你会失去什么？"** → 找出最小阻力路径与退出成本

三问答完，问题通常会自动变成一句可分析的话。这时再进五步流程。
