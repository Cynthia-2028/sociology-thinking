# 14 依据强度与边界说明

这份文件回答两个问题：**这套内容凭什么这么说？哪些地方要留一手？**

它不影响使用，但影响你说话的底气——知道哪句话能说满，哪句话要留余地。

---

## 一、材料构成

材料分三类，性质不同，能支撑的东西也不同：

| 类型 | 性质 | 主要支撑 |
|---|---|---|
| **导论型教材** | 学科共识的系统整理，覆盖面广、体系完整，但理论争论被简化 | 概念定义、知识地图、分支结构、教学式例子 |
| **思维取向类著作** | 论辩性强，风格鲜明，讲"怎么看"多于"有哪些" | 去自然化、位置感、分类与排斥、理性化批判、必死性分析 |
| **中国研究专题著作** | 经验研究为主，机制扎实，但案例有时空限定 | 治理机制、财政链条、基层运作、城乡制度、田野方法 |

**写作时的处理**：概念定义优先取教材共识；机制链条优先取经验研究；"怎么看世界"的部分取自思维取向类著作。三者冲突时，以经验证据为准，并在文中说明分歧。

---

## 二、精读方式与覆盖

不是通读，是**按主题分组精读 + 结构性跳读**：

- 教材类：核心章节（学科定位、理论、方法、分层、越轨、组织、教育）读全，其余章节读章首与章末小结。
- 思维取向类：正文主体读到六成以上，个别书目达八成以上。
- 中国研究专题：核心机制章节读到五成到七成，个案细节部分跳读。
- 论文选本类：按主题挑代表性篇目，读到三成左右。

**这意味着**：概念与机制的骨架是可靠的；具体个案的数字与细节，不宜当作定论引用。

## 四、已知局限（必须知道）

1. **以教科书共识为主，理论前沿覆盖不均。**
   遇到"某流派内部最新争论""近五年新提法"这类问题，本 skill 给不出可靠答案。正确做法是先说明边界，再答能答的部分。

2. **教材背景偏西方，中国部分另起一套。**
   概念的定义多来自西方教材，制度分析来自中国研究。两者衔接处的"概念折价"（见 SKILL.md 第 4 节）是编者所做，不是现成结论，遇到精细争论时要谨慎。

3. **统计数字有年代。**
   教材中的比例多截止于数年前，且以西方社会为背景；中国研究的财政、土地数据也有明确年份。凡引用数字，必须带年份与口径，并提示"以最新统计为准"。

4. **中国研究有时空限定。**
   多数经验研究基于特定区域、特定时期的调查。机制可以外推，比例不能。讲"某县如何"可以，讲"中国如何"要慎重。

5. **理论部分刻意去掉了人名与流派标签。**
   好处是可用、不背人名；代价是失去了学术史脉络，也无法用于精确的文献对话。写论文时需要补回具体出处——那时应查原始文献，不要拿这份文件当引用来源。

6. **案例库是推演，不是发现。**
   `07-case-library.md` 里的二十五个案例，情节是为了示范拆解方式而组织的。它们不构成经验证据，也不能当"研究表明"来引用。

7. **方法部分是规范，不是操作手册。**
   它告诉你"该问什么"，不告诉你"软件怎么点"。具体的抽样量、模型设定、编码流程，需要另找专门材料。

## 五、需要回查的清单（讲之前先核）

| 情形 | 为什么 | 怎么办 |
|---|---|---|
| 要引用具体百分比 | 数字有年份与口径 | 查最新统计年鉴或权威调查，标注年份 |
| 要说"研究表明" | 本文件不含可引用的文献信息 | 回到原始研究，确认结论与条件 |
| 要讲某项政策的现行规定 | 政策会调整 | 查官方最新口径，注明查询时间 |
| 要讲某个理论的内部争论 | 本文件只给教学式简化 | 说明"这是简化版"，或直接查原始论述 |
| 要用于论文、课题、正式报告 | 需要精确出处 | 本 skill 只能做思路与结构参考，引用必须另找来源 |
| 涉及法律、医疗、社保的具体问题 | 专业判断超出范围 | 讲机制与常见坑，明确建议咨询专业渠道 |

## 六、一条总原则

**能讲机制就讲机制，讲不了就说讲不了。**

宁可说"这个比例我没有可靠来源"，也不给一个看起来很像的百分比；宁可说"这只是一种整理方式"，也不把它说成"学界公认"。

这套东西的价值不在于显得权威，而在于**让读者拿到一个自己能验证、能修正的看法**。
