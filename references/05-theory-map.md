# 05 理论地图：七种回答方式，以及怎么比较它们

**这一份刻意不按人名组织。** 按人名背理论，考完就忘；按"它反对什么、它怎么解释、它解释不了什么"记，才能用。

---

## 一、七种回答方式（遇事先判断该调哪一种）

### 1. 功能取向（Functionalism）

| | |
|---|---|
| **反对什么** | 把社会现象还原为个人动机；认为"存在即偶然" |
| **核心命题** | 任何持续存在的安排，都在维持某种整体需要；要问"它让什么得以继续运转" |
| **关键概念** | 显功能、潜功能、反功能、未预期后果、制度化、社会化 |
| **能解释** | 为什么看似荒谬的安排能长期存在；为什么改革常失败（因为拆掉了没人注意的支撑） |
| **解释不了** | 变迁（谁在推动）、代价分配（谁受损）、权力（谁有权决定这是"需要"） |
| **典型方法** | 制度分析、比较个案、历史功能追溯 |
| **一句话软肋** | "位置会空着"这类推论几乎无法被证伪 |

**用法提醒**：讲功能必须配一段"谁付代价"。否则从解释滑向辩护，只差一句话。

---

### 2. 冲突取向（Conflict）

| | |
|---|---|
| **反对什么** | 功能取向的"整体需要"——谁定义需要？ |
| **核心命题** | 社会安排服务于一部分人的利益；稳定靠强制，也靠让人自我归因的说法 |
| **关键概念** | 支配、剥削、意识形态、合法化、社会封闭、文化霸权 |
| **能解释** | 不平等为何被忍受；为什么"公平"的话语总在特定时刻出现；制度为何偏向强者 |
| **解释不了** | 为什么被支配者常常真心认同；为什么有些制度对精英也不利（如社会保障） |
| **典型方法** | 历史比较、阶级/精英分析、话语分析 |
| **一句话软肋** | 容易把"有受益者"当成"有人策划" |

---

### 3. 互动与意义取向（Interpretive / Interactionist）

| | |
|---|---|
| **反对什么** | 把社会当物；忽略当事人如何理解自己的处境 |
| **核心命题** | 社会在面对面互动中被持续"做"出来；意义不是附带品，是原因 |
| **关键概念** | 情境定义、角色、印象管理、前台后台、标签、情感劳动、常人方法 |
| **能解释** | 同一制度下为何行为差异巨大；污名如何生效；秩序为何在日常层面如此脆弱又如此稳固 |
| **解释不了** | 制度为何是这样而不是那样；权力的物质基础；大规模变迁 |
| **典型方法** | 观察、深度访谈、会话分析、民族志 |
| **一句话软肋** | 容易只见树木不见森林，把结构问题写成"心态" |

---

### 4. 实践与场域取向（Practice / Field）

| | |
|---|---|
| **反对什么** | 结构与能动二选一；也反对把行动理解为理性计算 |
| **核心命题** | 行动者带着被位置塑造的倾向（惯习）进入场域，争夺有价值的资本；品味与身体本身就是等级 |
| **关键概念** | 场域、资本（经济/文化/社会/象征）、惯习、区隔、象征暴力、再生产 |
| **能解释** | 为什么不平等能代代相传而当事人不觉得被压迫；为什么"努力"在不同起点上收益不同；趣味如何标记阶级 |
| **解释不了** | 场域的起源与剧烈变迁；为何有人能跳出惯习；情感与道德体验的细腻差异 |
| **典型方法** | 对应分析、生活史、场域民族志 |
| **一句话软肋** | 决定论色彩强，变革空间小 |

---

### 5. 结构化与关系取向（Structuration / Relational）

| | |
|---|---|
| **反对什么** | 结构是"外在的物"；也反对行动完全自由 |
| **核心命题** | 结构只在被人持续遵循时存在；行动者同时生产与再生产规则与资源 |
| **关键概念** | 结构化、规则与资源、脱域、时空延伸、关系网络、弱关系、结构洞 |
| **能解释** | 为什么制度会突然崩塌（大家不再遵守）；为什么信息与机会沿关系网流动；为什么"认识谁"比"会什么"更重要 |
| **解释不了** | 为什么某些规则特别顽固（物质利益与暴力）；意义的厚度 |
| **典型方法** | 网络分析、过程追踪、制度民族志 |
| **一句话软肋** | "结构靠遵守而存在"解释不了强制 |

---

### 6. 理性化与现代性批判（Rationalization / Modernity）

| | |
|---|---|
| **反对什么** | 现代化=进步的直线叙事 |
| **核心命题** | 为效率设计的系统会长出自己的非理性；现代性的代价是个体被抽象系统接管 |
| **关键概念** | 理性化、铁笼、麦当劳化、目标置换、风险社会、个体化、液态现代性、去死亡化 |
| **能解释** | 为什么越高效的组织越让人窒息；为什么风险由个人承担；为什么"自由"伴随无力感 |
| **解释不了** | 具体的利益分配；为何同一理性化在不同社会后果不同 |
| **典型方法** | 概念分析、历史比较、文化诊断 |
| **一句话软肋** | 容易写成时代控诉，缺少可检验的经验命题 |

---

### 7. 文化与表演取向（Culture / Performance）

| | |
|---|---|
| **反对什么** | 文化是经济的影子；意义可以被还原为利益 |
| **核心命题** | 意义结构有自身语法与因果力；社会行动是面向观众的表演，成败取决于剧本、舞台与观众认同 |
| **关键概念** | 二元符码、叙事、文化创伤、公民领域、社会表演、象征权力、集体欢腾 |
| **能解释** | 为什么某些事件能成为"全民事件"；为什么有些正当性表演失败；集体身份如何被造出来 |
| **解释不了** | 物质利益的硬约束；表演失败后的强制手段 |
| **典型方法** | 厚描、文本与话语分析、过程追踪 |
| **一句话软肋** | 可证伪性弱，容易变成"什么都能解释" |

---

### 附：还有两条常被单独提起的路线

- **生命历程与生命策略取向**：把年龄、世代、时机（timing）作为结构变量。能解释"同一件事在不同年龄做，后果完全不同"（买房、生育、转行、考研）。核心概念：生命历程、世代单元、时机、生命策略、必死性。
- **后殖民与全球取向**：知识生产本身有位置；"普遍理论"常是特定经验的普遍化。核心概念：知识的地缘政治、hybridity、subaltern、殖民矩阵的批评。能解释为什么同一概念在非西方社会"水土不服"。

## 二、三视角对照法（最实用的比较工具）

**它解决什么**：同一个现象，为什么会有三种互相冲突的解释；以及这三种解释各自的盲区。

### 步骤

1. **定层**：把现象拆成微观（互动）、中观（组织）、宏观（制度）。明确你要解释哪一层的什么。层没定，三视角会各说各话。
2. **功能问**：它让什么得以继续运转？分列显功能、潜功能、反功能、未预期后果。
3. **冲突问**：谁受益、谁承担代价？服从靠强制、靠合法性，还是靠一套让人自我归因的说法？
4. **互动问**：日常层面，人用什么符号、脚本、前台后台，一步步把它"做"出来？
5. **对账**：三份答案在哪里互相矛盾。**矛盾处就是机制所在。**

### 判据
能同时说出一个"功能论解释不了的代价"和一个"冲突论解释不了的稳定"。

### 失效条件
现象主要受自然或技术约束（地震带建房、抗生素耐药）时三视角会空转；最常见的失败是只走第 2 步就收工，写成"积极作用与消极作用"。

## 三、理论比较的三问（回答"这两种说法有什么不同"时按此走）

1. **它们在回答同一个问题吗？**
   多数"理论之争"其实是各答各的。一个问"为什么稳定"，一个问"谁受益"，两者可以同时成立。
2. **分歧的根源是前提不同，还是证据不同？**
   - 前提不同：一方假设"社会需要可以先于分配被识别"，另一方假设"需要本身就是争夺的结果"。这种争论无法用数据裁决，只能换问题。
   - 证据不同：一方看长期结构，一方看即时效果。这种争论可以用更好的证据推进。
3. **什么证据能分开两边？**
   说得出，才是可检验的分歧；说不出，就是立场之争，应如实告诉用户"这是立场差异，不是事实分歧"。

## 四、五组经典对立（每个都能单独讲一节课）

### 1. 结构 vs 能动
- **结构派**：人按位置行动，换人不换结构，结果照旧。
- **能动派**：结构靠人持续遵守才存在，停止遵守它就崩。
- **解开的方式**：不问"谁决定谁"，问"在什么条件下，结构给出的是概率还是命令"。多数时候是概率；极端情形（监狱、饥荒）才接近命令。

### 2. 文化 vs 利益
- **利益派**：观念是利益的包装，追到底还是钱与权。
- **文化派**：利益本身要被定义，定义框架来自文化；同一利益可以引出相反行动。
- **解开的方式**：问"如果利益不变、只换说法，行为会变吗"。会变，文化有独立作用；不变，文化只是装饰。

### 3. 宏观 vs 微观
- **宏观派**：个体行为是结构的产物，研究个体是舍本逐末。
- **微观派**：宏观只是无数次互动的聚合，不研究互动就不知道机制。
- **解开的方式**：用"跨层翻译"——宏观约束如何变成中观考核，中观考核如何变成微观动作。三层都写到，争论自动消失。

### 4. 普遍 vs 特殊
- **普遍派**：存在跨社会的一般机制（如国家建设、市场扩张、地位竞争）。
- **特殊派**：每个社会的历史路径不同，套用普遍理论会造出假问题。
- **解开的方式**：先做"概念折价"（见 SKILL.md 第 4 节），说明哪些条件缺失、用什么替代机制补上。折价之后仍能解释，就是普遍机制；不能，就是地方性知识。

### 5. 价值中立 vs 介入
- **中立派**：研究阶段排除价值判断，才能看清。
- **介入派**：选题、概念、盲点都带着位置，中立是神话。
- **解开的方式**：区分三个环节——**选题**（必然有价值）、**取证**（可以且必须排除偏见）、**结论**（应区分事实与主张）。争论常因把三个环节混成一个。

## 五、怎么自学理论（不按人名背的做法）

**第一步：先建"问题清单"而不是"人物清单"**
把理论按它回答的问题归档：秩序怎么来？不平等怎么维持？意义怎么生成？变迁由什么推动？

**第二步：每个理论只记四件事**
① 它反对谁；② 它的一句话主张；③ 它最漂亮的解释案例；④ 它解释不了什么。

**第三步：用一个经验案例把三种理论各走一遍**
选一个你自己熟悉的场景（如"公司年会"），用功能、冲突、互动三种方式各解释一次。走完一遍，比读三章教材有用。

**第四步：读原著只读"对手戏"**
理论的生命在论战里。找同一问题的两种对立回答对着读，比顺着读一整本快得多。

**第五步：给自己出"反驳题"**
"如果我是冲突论者，我会怎么反驳这个功能解释？"能自问自答，才算真懂。

## 六、常见误答（有人问"××理论是什么"时别踩）

| 误答 | 为什么错 | 改法 |
|---|---|---|
| 按人名讲生平与著作年表 | 用户要的是"它能干什么"，不是传记 | 先给它的一句话主张，再给一个能用的场景 |
| 说"三大理论"就完事 | 三大理论是教科书简化，掩盖了实践取向、关系取向、文化取向 | 三大 + 两条补充（实践/关系、文化/表演），并说明为何这样分 |
| 把功能论说成保守、冲突论说成进步 | 这只是价值倾向，不是提问方式 | 说清各自问的问题不同：一个问"维持了什么"，一个问"谁受益" |
| 把理论争论说成"都有道理" | 和稀泥，用户学不到东西 | 指出分歧根源（前提/证据），并说"什么证据能分开两边" |
| 用理论术语解释理论 | 循环论证 | 每个术语后面必须跟一个具体例子 |
