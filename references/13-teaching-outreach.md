# 13 科普与教学：把社会学讲到别人听得懂、用得上

对象不同，讲法完全不同。先认人，再开口。

| 受众 | 他们要什么 | 不要什么 | 篇幅 | 起手式 |
|---|---|---|---|---|
| 朋友圈 / 短图文 | 一句能用的话 | 术语、铺垫、免责声明 | 200–600 字 | 一个反常识事实 |
| 长图文 / 公众号 | 一个完整解释 + 可转发的框架 | 学术黑话、无结论的综述 | 1500–3000 字 | 一个身边场景 |
| 课堂 | 能记住的结构 + 能练的动作 | 满堂灌、无例子的定义 | 45 分钟 | 一个让学生答错的问题 |
| 讲座 / 正式场合 | 一条清晰主线 + 边界 | 发散、跑题、过度承诺 | 30–60 分钟 | 一个数据或一个悖论 |

## 一、科普写作五步结构（最通用）

```
① 钩子：一个反常识的事实、一个身边场景、或一句人人都在说的话
② 翻转：外行会怎么解释，这个解释漏了什么
③ 概念：给它一个名字（术语出现立刻解释），并给判别标志
④ 机制：三环链条，每环一个具体细节
⑤ 收束：一句能记住的话 + 一个可自查的问题
```

**判据**：读者能用自己的话把这个机制复述给第三个人。做不到，就是没讲清。

**五个禁忌**：
1. 开头写"随着社会发展"——读者立刻划走。
2. 一段里三个新术语——读者放弃。
3. 只批判不给机制——读者觉得你在发泄。
4. 结尾喊口号——读者记不住。
5. 通篇没有具体的人、场景、数字——读者无感。

## 二、类比库（二十个，可直接用）

| 类比 | 讲什么 | 一句展开 |
|---|---|---|
| 河床与水 | 结构 vs 过程 | 一次洪水不改河道，常年冲刷会改 |
| 电梯与跑步 | 结构流动 vs 个人努力 | 电梯下行时，跑得快也上不去 |
| 铁笼与保险箱 | 科层制的两面 | 风险高时它是保险箱，风险低时它是铁笼 |
| 印钞与文凭 | 文凭通胀 | 印得越多，买同样东西要付越多 |
| 前台与后台 | 印象管理 | 没有后台的舞台，人会累死在表演上 |
| 剧本与演员 | 角色 | 演久了，人会变成角色；但也可以借角色办事 |
| 门票与入场券 | 资格与门槛 | 门槛先动，技能后动 |
| 筛子与梯子 | 教育是筛选还是上升通道 | 筛子越密，梯子越窄 |
| 棋盘与棋子 | 位置先于个人 | 换棋子不换棋盘，棋局照旧 |
| 站台与列车 | 机会结构 | 车次少了，跑得快也上不了车 |
| 红绿灯 | 规范 | 它既限制你，也让你敢踩油门 |
| 免疫系统 | 社会控制 | 过度反应会攻击自身 |
| 分蛋糕与做蛋糕 | 分配与增长 | 分配规则先于蛋糕大小 |
| 舞台灯光 | 可见性 | 被看见的位置，才有议价能力 |
| 河道改道 | 路径依赖 | 一旦绕开，旧河道很难再通水 |
| 传话游戏 | 信息失真 | 层级越多，信息越像谣言 |
| 两个闹钟 | 多重考核 | 两个都响时，人选最响的那个 |
| 雨伞与天气预报 | 风险与预期 | 预报越不确定，伞卖得越好 |
| 借书与藏书 | 文化资本 | 家里有书不等于会用图书馆 |
| 排队与插队 | 公平感 | 争的不是位置，是规则是否一致 |

## 三、标题与开头句式（二十条）

**反常识型**
- 你的私人烦恼，常常是别人的统计数字。
- 不是你不努力，是尺子在通胀。
- 越努力越穷？先看看你在哪个赛道上跑。

**换算型**
- 把这件事换算成钱、时间和风险，你会看到另一个故事。
- 一个家庭的账本，比十份报告更能说明问题。

**揭机制型**
- 这套安排里，有个所有人都在做、但没人说破的动作。
- 真正管着你的，不是领导，是那张表。

**提问型**
- 为什么医生越忙，你越觉得他没听你说话？
- 为什么"做工作"比"下文件"更贵，却更常用？

**概念型**
- 什么叫"结构"？就是换个人来，结果还是一样。
- 什么叫"位置"？就是你先坐下，规则才生效。

## 四、一图流设计（三个通用版式）

### 版式 A：三层同心圆
外圈宏观（制度）、中圈中观（组织）、内圈微观（互动）。每圈一句提问。用于讲"同一件事的三层解释"。

### 版式 B：链条图
横向 3–5 个方框，箭头相连，每个框下一行小字"判据"。用于讲机制（财政—行为链、标签五步、发包五要素）。

### 版式 C：四格矩阵
两维交叉出四格（如发包强度 × 竞争强度）。每格一句结论。用于讲类型与分布（治理能力强弱、四种家庭策略）。

**版式规矩**：一图只讲一件事；每格文字不超过 12 字；必须有标题句（读者只看标题也能懂）。

## 五、课堂活动（五个，都能在 45 分钟内完成）

### 活动 1：反常识测验（10 分钟）
出五道题，答案都与直觉相反（如"社会流动增加是否说明更公平"）。先让学生举手选，再公布答案与理由。
**目的**：制造认知冲突，让"社会学有用"变成体感。

### 活动 2：换位置实验（15 分钟）
给一个场景（如"部门群里老板发了条消息"），让学生分别站在老板、老员工、新人、实习生的位置写"我会怎么做、为什么"。
**目的**：体会"位置先于性格"，理解最小阻力路径。

### 活动 3：概念辨析二选一（15 分钟）
给四个案例，让学生判断"这是差异、支配还是压迫"，并说明判据。答案常有争议——争议本身就是教学材料。
**目的**：训练判据意识，避免概念通胀。

### 活动 4：田野小任务（课后）
让学生观察一个自己熟悉的场景（食堂排队、快递驿站、家族群），记录三条"大家都在做但没人说为什么"的动作，用四维模型（结构/文化/人口/技术）各写一句。
**目的**：把"去自然化"变成可练习的动作。

### 活动 5：理论对照表（20 分钟）
同一个案例，分三组分别用功能、冲突、互动三种方式解释，然后互评"你解释不了什么"。
**目的**：理解理论的边界，而不是背理论。

## 六、短视频 / 口播脚本结构（60–90 秒）

```
0–3 秒   钩子：一句反常识或一个冲突场景
3–15 秒  翻转：大家通常怎么解释，哪里不对
15–50 秒 机制：三步链条，每步一句人话 + 一个画面
50–70 秒 代价：谁受益、谁付账
70–90 秒 收束：一句能记住的话 + 一个提问（引导评论）
```

**两个要点**：
- 每一句都要能被"听不懂的人"接住，术语出现立刻用括号解释；
- 结尾的提问要具体（"你身边有没有这种事？"），不要问"你怎么看"。

## 七、六种讲砸的姿势

| 姿势 | 表现 | 改法 |
|---|---|---|
| 概念倾倒 | 一分钟抛五个术语 | 一个段落只留一个新词 |
| 道德优越 | 全程批判，读者被当成批判对象 | 先承认常识抓住的部分，再指出缺口 |
| 无主体结构 | "社会让人……" | 换成"这套考核让坐这个位子的人……" |
| 假深刻 | 用"内卷""异化""资本逻辑"收尾 | 术语后面必须跟可观察的关系 |
| 无边界 | 结论说成普适 | 加一句"在××条件下会失效" |
| 过度承诺 | "看懂这个就能改变命运" | 改成"看懂这个，你至少知道账是怎么算的" |

## 八、如何回答"学这个有什么用"

不要答"培养批判性思维"（太虚）。给三个具体用途：

1. **少自责**：知道哪些是你的问题、哪些是位置的问题，能省下大量内耗。
2. **会看账**：任何一件事，能快速问出"谁受益、谁付账、钱从哪来"。
3. **能预判**：知道考核怎么改、行为就会怎么变；知道路径在哪，就知道改变要从哪下手。

一句收尾：**社会学不承诺让你过得更好，它承诺让你知道自己站在哪。**
