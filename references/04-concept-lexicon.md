# 04 概念词典

四列：**定义**（一句话，含它反对什么）、**判别标志**（怎么看出它成立）、**常见误用**（最容易被用歪的地方）。
按主题分组；括号内为英文，便于检索与写作时对照。

---

## A 学科与思维

| 概念 | 定义 | 判别标志 | 常见误用 |
|---|---|---|---|
| 社会学（sociology） | 系统研究人如何被社会结构与社会过程塑造、又如何反过来塑造它们 | 解释里同时出现"人的行动"与"超出个人的结构" | 当成"研究社会问题"——它更常研究"问题如何被定义成问题" |
| 社会学想象力（sociological imagination） | 把个人处境放回历史与结构中看的能力 | 能把"我很累"改写成"这批人的处境在变" | 当成"同情心"或"批判精神" |
| 私人困扰 / 公共议题（personal trouble / public issue） | 一个人遇到是困扰，很多人同时遇到就是议题 | 出问题的人数达到规模，且成因不在个体内部 | 把所有困扰都公共化，推卸个人责任 |
| 社会建构（social construction） | 人通过行动造出看似自然的现实，该现实随后反过来约束人 | 能指出被造出来的那一刻，以及它后来怎样"独立" | 读成"其实是假的"——建构讲意义与后果，不否认物质性 |
| 情境定义（definition of the situation） | 情境的性质由参与者共同定义，定义一变后果就变 | 同一物理事实因定义不同而有不同后果 | 以为"定义"是主观任意，忽略定义也受权力约束 |
| 自我实现的预言（self-fulfilling prophecy） | 预期通过行为改变对象，使预期成真 | 找得到"预期→差别对待→对象改变"的链条 | 用来解释一切失败，变成循环论证 |
| 理想类型（ideal type） | 刻意夸大某些特征造出的标尺，不是现实写照 | 使用者清楚它是量尺而非描述 | 拿它当"现实应该长这样"的标准 |
| 显功能 / 潜功能 / 反功能 | 有意的正效果 / 意外的正效果 / 削弱系统的后果 | 三者能分开陈述，不混成"有好有坏" | 把潜功能讲成阴谋（背后有人操纵） |
| 未预期后果（unintended consequence） | 意图与结果之间被社会机制扭转 | 能指出中间环节，而非只能说"没想到" | 当成"无人负责" |
| 路径依赖（path dependence） | 早期选择通过沉没成本与配套安排锁死后来的选项 | 能指出"当初的小差别如何被放大成不可逆" | 当成"历史决定论" |
| 机制（mechanism） | 可指认的、在特定条件下反复发生的因果环节 | 能回答"为什么是这个时间、这个地点、这批人" | 用相关代替机制；用术语代替机制 |
| 价值中立（value neutrality） | 数据收集与推理环节排除偏见，而非取消立场 | 方法与程序可被他人重做 | 当成"没有价值观"或"什么都对" |

## B 文化

| 概念 | 定义 | 判别标志 | 常见误用 |
|---|---|---|---|
| 文化（culture） | 一个人群的思考方式、行动方式与物质造物的总和 | 可传递、可学习、非本能 | 窄化为"读书看展听音乐会" |
| 象征（symbol） | 承载特定意义、并被同一文化成员识别的事物 | 换一个文化就读不懂，或读成相反意思 | 把象征当成"装饰" |
| 价值 / 信念（values / beliefs） | 价值是"什么是好"的抽象标准；信念是"什么是真"的具体判断 | 价值冲突时人会出现双重标准 | 把价值当事实来论证 |
| 规范（norms） | 带奖惩的行为规则，即"长了牙的价值" | 越界后有社会后果，而非只有物理后果 | 以为规范只是限制，忽略它也生产可预期性 |
| 民俗 / 民德（folkways / mores） | 轻微规则（得体与否）/ 严重规则（对错） | 看违反后的制裁强度 | 混用，导致把"不得体"说成"不道德" |
| 亚文化 / 反文化（subculture / counterculture） | 在一社会内部共享独特意义系统的群体 / 明确对抗主流者 | 有自身语汇、仪式、边界维护 | 把任何兴趣群体都叫亚文化 |
| 文化资本（cultural capital） | 家庭带来的品味、语言、见识等可兑换的优势 | 控制收入后，它仍能预测成绩与机会 | 混同于"学历"或"读过很多书" |
| 文化滞后（cultural lag） | 物质技术变化快于规范与观念 | 出现"技术已普及、规矩还没定"的窗口 | 当成"观念落后"的道德批评 |
| 文化再生产（cultural reproduction） | 学校与家庭把一代人的位置传给下一代，并以"能力"名义正当化 | 分流与家庭背景高度相关，且被解释为天赋 | 当成"学校在教文化" |
| 符码（code） | 一套二元对立，决定什么算正常、什么算越界 | 能列出对立项（纯洁/污染、自力/依赖） | 当成"密码"或"暗号" |

## C 社会化与互动

| 概念 | 定义 | 判别标志 | 常见误用 |
|---|---|---|---|
| 社会化（socialization） | 人借社会经验发展人性、学习文化的终身过程 | 剥夺社会接触会出现不可逆损伤 | 只讲童年，忽略成年后的持续社会化 |
| 再社会化 / 全控机构（resocialization / total institution） | 通过控制环境彻底改写自我 / 剥夺旧身份并重建新身份的场所 | 有剥夺与重建两阶段 | 把寄宿学校、军训一律算作全控机构 |
| 身份 / 角色（status / role） | 身份是位置；角色是对该位置的期待 | 角色冲突跨身份，角色紧张在同一身份内 | 把角色当成"假面"，以为"做自己"可以完全脱离角色 |
| 角色距离（role distance） | 一边演一边示意"我不是这个角色" | 有自嘲、走神、摸鱼、过分夸张等出戏信号 | 当成"不敬业" |
| 印象管理（impression management） | 为在他人心中制造特定印象而进行的表演 | 有前台/后台、道具、布景、救场话术 | 当成"虚伪"——多数表演是无意识的 |
| 前台 / 后台（front stage / back stage） | 表演区与放松区；数字时代后台常被取消 | 能找到观众、剧本与表演失败的代价 | 忽略"中台"（半公开场合）的存在 |
| 情感劳动（emotional labor） | 工作要求你管理自己的情绪表达 | 有"必须微笑/必须耐心"的成文或不成文规定 | 混同于"体力劳动"或"情绪化" |
| 参照群体（reference group） | 人用来评价自己的那群人 | 换了参照群体，同一处境的主观感受会变 | 当成"攀比" |
| 镜中我 / 泛化他人（looking-glass self / generalized other） | 自我来自"我以为别人怎么看我"的内化 / 内化的社会一般期待 | 同一人身上"即时冲动"与"内化期待"比例可辨 | 当成"在意别人看法"的通俗说法 |

## D 组织

| 概念 | 定义 | 判别标志 | 常见误用 |
|---|---|---|---|
| 科层制（bureaucracy） | 按分工、层级、成文规则、技术资格、非人格化组织起来的行动方式 | 换人后行为不变；个案必须变成类别 | 当成"低效"——理想型的科层制是效率工具 |
| 非正式组织（informal organization） | 组织实际运转所依赖的关系与小道消息 | 能找到稳定的"绕过流程" | 当成"腐败"，忽略它是润滑剂 |
| 寡头铁律（iron law of oligarchy） | 有组织就有少数人掌权 | 程序齐全而决定在小圈子完成 | 当成"所有组织都独裁" |
| 目标置换（goal displacement） | 手段变成目的，原目标被悄悄替换 | 报表漂亮、问题照旧 | 当成"执行不力" |
| 麦当劳化（McDonaldization） | 效率、可计算、可预测、控制四项原则扩散到全社会 | 四项同时上升，且出现"理性的非理性" | 当成"快餐业研究" |
| 单位制（danwei system） | 功能合一、非契约、资源不可流动的组织形式 | 生老病死仰赖单位；退出成本极高 | 以为它已消失——它变成"身份"与"资格"延续 |
| 项目制（project-based earmarking） | 财政资金以项目形式下达，专款专用、逐项申报验收 | 资金绕过本级预算、需配套、需报批 | 当成"项目管理"的技术问题 |
| 平台（platform） | 以数据与规则中介供需、把管理权写进协议的组织形态 | 指令来自参数而非工头；责任被移出组织 | 当成"中介"或"市场" |

## E 越轨与社会控制

| 概念 | 定义 | 判别标志 | 常见误用 |
|---|---|---|---|
| 越轨（deviance） | 被多数成员认定违反规范并可能受谴责的行为 | 关键在"被认定"，不在行为本身 | 当成"坏行为"——过度正直的人也会越轨 |
| 失范（anomie） | 社会缺乏道德指引，欲望无标准、目标与手段脱节 | 目标被普遍鼓励，手段被结构性堵住 | 混同于"没有规范"；也常与"手段—目标脱节"混用 |
| 标签论（labeling theory） | 越轨是标签成功施加的结果 | 能找到贴标签的人、被贴的人、贴之后的身份变化 | 当成"替越轨者开脱" |
| 初级 / 次级越轨（primary / secondary deviance） | 偶发行为 / 围绕标签重组生活 | 被公开命名后，人开始按名字活 | 把次级越轨当成"本性暴露" |
| 污名（stigma） | 被认定为不寻常且令人不快的特征 | 有"我们—他们"的隔离技术与解释话术 | 当成"个人缺点" |
| 道德恐慌（moral panic） | 对某种越轨不成比例的集体反应，常以一个象征群体为载体 | 危害被夸大、个案被当群体特征 | 当成"公众关心" |
| 社会控制（social control） | 使人们遵守规范的各种机制（从眼色到监狱） | 有分层级的制裁体系 | 只想到警察与法院，忽略日常控制 |
| 医疗化（medicalization） | 把原本属于道德、法律或教育的问题改写成"病" | 出现诊断标准、治疗方案、保险支付 | 当成"科学进步"或"纯粹坏事" |

## F 分层与流动

| 概念 | 定义 | 判别标志 | 常见误用 |
|---|---|---|---|
| 分层（stratification） | 社会把人群按等级排列的系统 | 代际传递 + 有正当化意识形态 | 缩成"收入差距" |
| 三维不平等（class / status / power） | 经济、声望、支配能力三个维度可错位 | 出现"地位不一致"（高收入低声望等） | 只测一维就下结论 |
| 社会流动（social mobility） | 在等级中位置的变动；分上下、水平、代际、代内、结构 | 区分"个人位置变了"与"位子总数变了" | 用绝对流动率证明"更公平" |
| 先赋 / 自致（ascribed / achieved） | 出身带来的 / 靠努力获得的 | 控制先赋项后，自致项的净效应有多大 | 以为现代社会已以自致为主 |
| 生活机会（life chances） | 位置给出的概率与容错空间，不是个人命运 | 同能力不同位置，结果差很远 | 当成"宿命" |
| 社会封闭（social closure） | 优势群体用资格、执照、门槛把后来者挡在外面 | 门槛先动、技能后动 | 当成"竞争激烈" |
| 文凭主义（credentialism） | 学历与高地位岗位挂钩，学历增长快于技能需求 | 岗位内容不变而要求提高；文凭不能"关门"则只是符号 | 当成"重视教育" |
| 区隔（distinction） | 用品味差异标记并维持等级 | 同一功能的东西，因品味被排出高低 | 当成"审美差异" |
| 贫困的文化解释 | 把贫困归因于穷人的价值与习惯 | 忽略结构、健康、网络的位置效应 | 常被误当作"社会学观点"，其实是它批判的对象 |

## G 家庭与性别

| 概念 | 定义 | 判别标志 | 常见误用 |
|---|---|---|---|
| 婚姻市场（marriage market） | 婚配是在受限的供需结构中完成的 | 同类婚配稳定出现，只是筛选语言变了 | 当成"物化感情"的道德判断 |
| 家务分工 / 第二轮班 | 有偿工作之外，家务与照料的第二次轮班主要落在女性身上 | 时间使用数据中差距稳定存在 | 当成"谁更爱干净" |
| 照料劳动（care work） | 维系人的身体与情感的工作，常不被计酬 | 有人退出时，系统立刻出问题 | 当成"天生的母职" |
| 代际交换（intergenerational exchange） | 抚养与赡养之间以"报"为核心的长期均衡 | 无精确计量，靠心安与社区评价结算 | 用经济合同逻辑硬套 |
| 性别表演（doing gender） | 性别不是属性，是在互动中持续"做"出来的 | 同一人换场景，性别表现会调整 | 当成"装扮"或"表演欲" |
| 交叉性（intersectionality） | 多重身份（性别、阶层、城乡、年龄）叠加产生独特处境 | 单一维度的解释在同一人身上失效 | 当成"身份清单"，把所有维度并列而不看互动 |

## H 教育、宗教与知识

| 概念 | 定义 | 判别标志 | 常见误用 |
|---|---|---|---|
| 学校效应（school effect） | 学校间资源差异对成绩的解释力，远小于家庭背景 | 入学时差距已存在，甚至幼年可测 | 当成"学校不重要" |
| 分流（tracking） | 按成绩/性向把学生分到不同轨道 | 分流与家庭背景高度相关，且难逆转 | 当成"因材施教" |
| 隐蔽课程（hidden curriculum） | 学校在正式课程之外教的东西（守时、排队、服从） | 规则、空间、评价方式本身在传递价值 | 当成"校规" |
| 世俗化（secularization） | 宗教在公共生活中的地位下降 | 同时出现基要主义与新灵性的增长 | 当成"宗教会消失" |
| 仪式（ritual） | 按固定程序进行的象征性行动，制造联结与权威 | 有程序、有观礼者、有身体动作 | 当成"形式主义" |
| 集体欢腾（collective effervescence） | 群体聚集时产生的亢奋与认同强化 | 大型集会、赛事、葬礼后的"我们感" | 当成"情绪传染" |

## I 城市、乡村与环境

| 概念 | 定义 | 判别标志 | 常见误用 |
|---|---|---|---|
| 城乡二元（urban-rural dualism） | 按户口划身份、据此分配资源与机会的制度体系 | 同一人仅因户口适用不同规则 | 当成"收入差距"或"发展阶段" |
| 社区（community） | 以地缘、关系与共同事务为基础的联结 | 有共同事务可议、有问责渠道 | 当成"小区"这个物理单位 |
| 士绅化（gentrification） | 资本与高收入者进入旧城区，原住民被价格挤出 | 房租上升快于收入，店铺类型更替 | 当成"城市更新"的中性说法 |
| 生态位（niche） | 人群在空间、资源与其他群体关系中的位置 | 空间布局直接改变互动成本 | 当成"地理位置" |
| 风险社会（risk society） | 风险从自然危害转为科技与制度决策的产物，且跨阶级全球化 | 有人为来源、难计量、后果跨代 | 当成"现在更危险" |
| 邻避（NIMBY） | 承认公共设施必要，但反对建在自己附近 | 反对理由从"不需要"转为"别在我这" | 当成"自私" |

## J 国家、治理与中国经验

| 概念 | 定义 | 判别标志 | 常见误用 |
|---|---|---|---|
| 国家能力（state capacity） | 国家实际渗透社会、执行决策的能力 | 主张得到批准，但落实不下去 | 混同于"权力大小" |
| 专断权力 / 基础权力 | 不经协商即可主张的权力 / 实际渗透与执行的能力 | 能下令，但不能落地 | 只看到前者 |
| 权威类型（传统 / 魅力 / 法理） | 服从之所以成立的理由 | 同一句话，不同权威下效果不同 | 当成"历史阶段论" |
| 财政社会学（fiscal sociology） | 从"钱从哪来、怎么分"解释政府行为 | 能由收入结构推断行为方向 | 当成"财政技术问题" |
| 一统体制 / 有效治理 | 中央保有最终决定权 / 基层解决具体问题的实际能力 | 两者存在结构性张力，钟摆式摆动 | 当成"集权 vs 分权"的简单选择 |
| 运动型治理 / 常规型治理 | 暂停常规程序、集中动员 / 按分工规章办事 | 是否叫停常规、是否跨部门抽人、有无终点 | 把一切集中行动都叫运动 |
| 行政发包（administrative subcontracting） | 统一权威内部植入发包：事权打包、经费自筹、结果问责 | 三要素同时成立才算，缺一只是分权 | 当成"分权改革" |
| 晋升竞争（tournament mobility） | 同级主官围绕可测指标竞争晋升 | 人事权集中、指标可比、承诺可信 | 当成"官员只认 GDP" |
| 共谋 / 变通（collusion / workaround） | 直接上下级联手应付更上级 / 名义照办实际改办 | 检查前打招呼、检查中陪同；名义与实际有落差 | 一律当成"腐败" |
| 属地管理 / 条块结合 | 按地界划责任 / 职能部门纵向与属地横向叠加 | 同一事项能同时找到"主管部门"与"属地" | 当成"重复管理"的冗余 |
| 悬浮型政权（floating regime） | 基层政府不再从农民汲取、也不再直接服务农民 | 不收钱、不办事、与村庄失去日常联系 | 当成"服务型政府转型成功" |
| 差序格局（differential mode of association） | 以己为中心、按亲疏远近配置信任与资源 | 同一规则对不同关系的人宽严不同 | 当成"社会网络"或"自私" |
| 人情 / 面子（renqing / mianzi） | 以礼物、劳务、宴请为载体的长期互惠账户 / 公开的社会评价 | 欠人情要还；不给面子即断关系 | 一律当成"腐败" |
| 人格化联系（personalized linkage） | 治理者以具体的人对具体的人的方式建立联结 | 因人而异、留缓冲、先谈后罚 | 当成"人治落后" |

## K 方法与推理

| 概念 | 定义 | 判别标志 | 常见误用 |
|---|---|---|---|
| 相关 / 因果 | 同时变化 / 一个的变化引起另一个的变化 | 有时间顺序、有机制、能排除竞争解释 | 把相关当因果 |
| 反事实（counterfactual） | "如果没这么做会怎样"的对照推理 | 能说出替代状态是什么 | 用想象代替可比对照 |
| 内生性（endogeneity） | 解释变量与误差项相关，导致估计偏误 | 有遗漏变量、反向因果、选择偏误 | 当成"数据质量问题" |
| 抽样（sampling） | 从总体中按规则抽取子集 | 知道抽样框与权重 | 用便利样本推断总体 |
| 效度 / 信度（validity / reliability） | 测到了要测的东西 / 重复测量结果稳定 | 有构念效度检验、有重测 | 只报告信度，不报告效度 |
| 个案外推（case generalization） | 个案不推算比例，而是让机制可见 | 写明支撑条件与负向边界 | 用一个个案断言"全国都这样" |
| 过程追踪（process tracing） | 沿时间顺序还原因果链条 | 每一环有证据，顺序不可倒 | 把叙事当证据 |
| 厚描（thick description） | 把行为放回当地意义系统中描述 | 局外人能读懂"这为什么算失礼" | 当成"细节多" |
| 三角验证（triangulation） | 用多种数据源/方法互相校验 | 报表、账本、闲谈三条线对照 | 把"多找几个人说"当验证 |
