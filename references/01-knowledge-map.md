# 01 知识地图：社会学在问什么，分成几块

## 一、四个母题（所有分支都是这四个的变体）

社会学的全部问题，最后都能归到四句话上。判断一个题目属不属于社会学，就看它能不能挂到这四根钉子上。

| 母题 | 问法 | 反面（不是社会学问法） | 典型题目 |
|---|---|---|---|
| **秩序** | 为什么这么多人能凑在一起过日子而不打起来？ | "人应该怎样" | 陌生人社会为什么可行；社区靠什么维持；规则为什么会被人遵守 |
| **不平等** | 谁在上谁在下，这个上下怎么被传下去、怎么被说成合理？ | "谁更努力" | 阶层再生产；城乡差距；性别分工；教育分流 |
| **意义** | 这件事对当事人意味着什么，这个意义是怎么被造出来的？ | "这件事客观上是什么" | 面子；污名；身份认同；消费的符号性 |
| **变迁** | 什么力量让一套安排松动、又让另一套长出来？ | "时代在进步" | 城市化；数字化；家庭形态变化；运动式治理的起落 |

**用法**：拿到一个问题，先问它挂在哪根钉子上。挂在两根以上的，往往是好题目（如"考公热"= 不平等 + 变迁 + 意义）。

## 二、领域地图（十二块）

| 分支 | 核心问题 | 关键概念 | 常用方法 |
|---|---|---|---|
| 社会学的思维与学科定位 | 社会学与常识、心理学、经济学差在哪 | 社会学想象力、私人困扰/公共议题、价值中立、去自然化 | 概念分析、思想实验 |
| 文化 | 人为什么这样想、这样分类 | 象征、价值、规范、民俗/民德、文化资本、文化滞后、亚文化 | 文本与符号分析、访谈 |
| 社会化与互动 | 人怎么变成社会人，日常怎么运转 | 初级/次级社会化、再社会化、全控机构、角色、印象管理、前台后台、情感劳动 | 观察、访谈、会话分析 |
| 组织与科层 | 为什么理性的设计长出荒唐的结果 | 科层制、非正式组织、寡头铁律、目标置换、麦当劳化、单位制 | 个案研究、组织档案 |
| 越轨与社会控制 | 谁有权力把一件事叫"问题" | 越轨、失范、标签、污名、道德恐慌、次级越轨、社会控制 | 统计、档案、媒体分析 |
| 分层与流动 | 位置怎么排、怎么传、怎么被正当化 | 阶级/地位/权力、社会流动、先赋/自致、文凭主义、生活机会、贫困文化批判 | 大型调查、流动表 |
| 家庭与性别 | 亲密关系如何被制度安排 | 婚姻市场、家务分工、第二轮班、代际交换、照料劳动、性别表演 | 调查、访谈、时间使用 |
| 教育 | 学校是筛选还是培养 | 文化再生产、学校效应、分流、文凭信号、隐蔽课程 | 追踪数据、民族志 |
| 宗教与信仰 | 神圣/凡俗如何划分，现代还信什么 | 神圣与凡俗、世俗化、基要主义、仪式、集体欢腾 | 历史比较、田野 |
| 政治与经济 | 权力与资源如何组织 | 权威类型、国家能力、财政、市场的社会建构、平台经济 | 比较历史、制度分析 |
| 城市、乡村与环境 | 空间如何塑造关系 | 城乡二元、社区、士绅化、生态位、风险社会 | 空间分析、田野 |
| 人口与变迁 | 人数与结构怎么改变一切 | 人口转变、年龄结构、迁移、社会运动、集体行为 | 人口统计、事件分析 |

## 三、概念的三层归属（定位工具箱）

同一件事在三层有不同名字、不同解释。这是初学者最容易混的地方。

| 层 | 你在解释什么 | 该用的概念 | 例子（以"加班"为例） |
|---|---|---|---|
| **微观** | 面对面互动中的意义与策略 | 角色、印象管理、面子、情感劳动、前台后台 | 老板在场时不敢先走；群里回"收到"的速度 |
| **中观** | 组织、群体、社区的规则与考核 | 科层制、考核指标、非正式组织、单位、行业惯例 | 绩效排名、加班时长计入考核、部门人少活多 |
| **宏观** | 制度、财政、政策、全球结构 | 劳动法执行、产业位置、城乡二元、全球价值链 | 代工利润薄、地方要保就业、社保成本 |

**规矩**：回答时要说清"我在讲哪一层"，并说明与邻层的关系。跨层不交代，读者会觉得你在偷换概念。

## 四、三条学习路径（按目的选，不要混着走）

### 路径 A：问题驱动（适合科普作者、非科班、想马上能用）
```
一个身边的困惑（为什么家长群这么累）
→ 三层定位，找出它主要在哪一层
→ 调 2–3 个概念（印象管理、前台/后台、考核指标）
→ 走一遍机制链
→ 找一个反例修正
→ 输出：一段能讲给朋友听的解释
```
优点：记得住。缺点：概念不成体系。

### 路径 B：理论驱动（适合要考试、要写论文、要教课）
```
四条母题 → 挑一条（如"不平等"）
→ 看这条主线上的三到四种回答（功能取向、冲突取向、实践取向、关系取向）
→ 每种回答只抓三样：它反对什么、它怎么解释、它解释不了什么
→ 用同一个经验案例把这几种回答各走一遍
→ 输出：一张对照表（不是背书）
```
关键：**不要按人名背理论，按"回答了什么、反对了什么"记**。

### 路径 C：方法驱动（适合要做经验研究）
```
先有问题（一句可证伪的"为什么"）
→ 判断它需要什么证据（分布？机制？过程？意义？）
→ 选方法（调查/访谈/田野/比较历史/文本与计算）
→ 设计抽样与测量
→ 预设"什么结果会推翻我"
→ 输出：一页研究设计
```
见 `06-methods-map.md`。

## 五、一张总图（口头讲给别人听时按这个顺序）

```
         ┌── 人怎么被做成社会人（社会化、互动、角色）
社会 ────┼── 人怎么被排成上下（分层、流动、教育、性别、城乡）
         ├── 人怎么被组织起来（组织、科层、单位、网络、平台）
         ├── 人怎么被定义成问题（越轨、标签、污名、道德恐慌）
         └── 这一切怎么变（人口、技术、运动、治理方式）
```

讲科普时，一条线讲完再讲下一条，不要五条线一起开。
