# 09 财政、土地与地方政府行为

**一句话总纲：任何"为什么基层/地方这样做"的问题，不查钱从哪来、怎么分，答案八成是错的。**

财政不是技术细节，是理解政府行为的入口。它把"作风问题""态度问题""能力问题"还原成一组可计算的约束。

---

## 一、起点：财权与事权的不对称

- **财权**：收钱的权（税种、税率、分成比例）。
- **事权**：办事的责（教育、医疗、基础设施、治安、社保）。

中国的地方政府承担了绝大部分支出责任（多数量级上，地方支出占全国财政支出的八成以上），但收入只占一半左右。差额靠**转移支付**填补。

**这个结构决定了三件事**：
1. 地方必须"找钱"——找上级、找土地、找银行；
2. 上级的钱带着条件（专项、配套、考核），不是自由支配；
3. 越到基层，责任越具体、财力越薄、自主权越小。

---

## 二、分税制：一次改变地方行为的改革

**核心动作**：按税种划分中央税、地方税、共享税；分设两套税务机构；把当时最大的税种（增值税）大头划归中央。

**直接后果**：
- 中央收入比重从约两成升到五成以上（具体数值随年份变动，量级如此）；
- 地方"交上去的多、留下来的少"，必须另找财源；
- 找到了两样：**土地**与**借债**。

**这不是谁的设计失误，是一次财政重组后的必然适应。** 讨论此后二十年的地方政府行为，都从这里开始。

## 三、土地财政与土地金融：一条自我加速的链条

### 3.1 五个环节

```
① 征地（农地转国有，补偿按原用途年收益倍数计）
   ↓
② 出让（工业用地低价甚至补贴；商住用地限量高价）
   ↓
③ 抵押（以土地或未来出让收益作抵押，通过融资平台取得贷款）
   ↓
④ 基建（道路、管网、场馆、新区）
   ↓
⑤ 地价上升 → 回到 ①
```

### 3.2 三笔账（讲清楚这套机制的必备）

1. **出让净收益**：扣掉补偿、开发、税费后，通常只占出让总额的一小部分（量级在百分之十几到三十之间）。
2. **土地相关税收**：直接与间接税收合计，约占地方收入的三分之一上下。
3. **抵押撬动倍数**：城市建设资金中，财政资金约占三分之一，金融约占三分之二——**真正的大头是借来的，不是卖地来的**。

**所以"土地财政就是卖地赚钱"是错的**。它的核心不是卖地收入，而是**土地作为信用凭证**：有地就能抵押，能抵押就能借钱，能借钱就能建设，建设推动地价，地价支撑下一轮抵押。

### 3.3 载体与信号

- **载体**：城投公司、土地储备中心、园区开发公司。谁持有土地证，谁就是借款主体。
- **还款来源**：土地出让收入、财政补贴、政府承诺函。靠"借新还旧"维持即已进入滚动状态。
- **危险信号**：出让收入下降、补贴跟不上、还息靠新债、项目停工。

### 3.4 判据与失效

**判据**：能画出资金闭环；能解释"新区先于人口"、"工业用地占面积一半却贡献极少收入"；能预测地价下行时的连锁反应。

**失效条件**：人口净流出、地价长期下行；中央限制平台融资、问责隐性债务、剥离政府担保；征地拆迁成本高到出让收支倒挂；城市进入存量更新，新增建设用地需求消失。

## 四、项目制：钱如何绕过基层财政

**定义**：上级资金以"项目"形式下达——定用途、定科目、"戴帽"，专款专用，逐项申报验收。

**六步运作**：
1. **设专项**：上级定用途、定科目，地方不得挪用。
2. **跑项目**：包装、申报、找关系。分配依据从"需求"偏向"能力"与"门路"。
3. **配资金**：要求自筹配套，于是出现"假配套""一女多嫁"（一笔钱给多个项目当配套）。
4. **批复**：典型是"两上两下"——学校报教育局、教育局报财政、县长批示、财政核查后付款。
5. **执行**：由县级职能部门直接实施，资金"绕开"乡镇财政；乡镇只剩配合与协调。
6. **验收与留痕**：审计、绩效评价、台账、照片、签字，形成大量"可被检查"的工作。

**它改变了什么**：
- 基层政府的角色从"分配者"变成"跑项目的人"；
- 乡镇财政被架空（钱不经过它），"有财无政"；
- 公共服务碎片化（一所学校买桌椅都要报专项）；
- 新增一类"项目型干部"，其激励与考核围绕申报成功率。

**判据**：资金是否绕过本级预算；是否出现普遍配套压力；分配是否呈"会哭的孩子有奶吃"。

**失效条件**：改为按公式分配的一般性转移支付；项目过小过散，交易成本高于收益；绩效评价真正硬化、可追责。

## 五、经营城市：政府像公司一样运作

**五个观察点**：
1. **增长联盟**：政府、平台、银行、开发商是否形成稳定合作。
2. **收入依赖**：土地出让 + 建筑业与房地产业税收合计占比。占比越高，越倾向扩张用地。
3. **支出偏向**：基建、新区、地标 vs 教育、医疗、地下管网。
4. **定价策略**：工业用地低价（甚至补贴）换税收与就业；商住用地限量高价换出让金——**交叉补贴**是核心手法。
5. **风险转嫁**：债务留给下一任、成本转给被征地者、房价转给新市民。

**判据**：能解释"为什么工业用地价格涨幅远低于住宅用地"；"为什么到处建新区却少有新产业"；"为什么地方对楼市调控总是软执行"。

**失效条件**：地方主体税种建立（收入与土地脱钩）；土地市场冷却；考核转向民生与债务；城市进入存量更新。

## 六、事权划分三原则（判断"这事该谁管"）

| 原则 | 问法 | 例子 |
|---|---|---|
| **外部性** | 受益或受损范围是否超出辖区？ | 流域污染、跨市道路 → 上交或跨区协调 |
| **规模经济** | 覆盖人越多越划算，但服务半径受制于获取成本 | 电网、供水 → 适度集中；社区服务 → 下沉 |
| **信息复杂性** | 谁掌握关键信息、谁承担后果 | 教材中央统编（标准统一），校舍地方出钱（信息在地方） |
| **激励相容** | 评价绩效的、决定内容的、承担后果的，是否同一个上级 | 三者分离必出扭曲 |

**判据**：能解释"国防中央出、教师工资地方出、教材中央统编"这类看似奇怪的组合。

**失效条件**：政治责任与属地责任压倒技术逻辑；跨域外部性在缺乏上级协调时无解；信息优势方恰好是问题制造者。

## 七、五个可操作框架

### 框架 A：「财政—行为」推断链（最常用）
1. 定位收入结构：本级税收、上级转移、非税与土地、借债各占多少；关键是"边际上多收一元归谁"。
2. 定位支出刚性：人头费占比、"三保"（保工资、保运转、保基本民生）中哪一保被放弃、有无配套要求。
3. 定位考核与任期：谁评价他、评价什么、多久调走。
4. 推断可选行动集：在"不能加税、不能收费、不能裁员"下还剩哪几条路。
5. 找行为痕迹：空转、欠款、卖资产、跑项目、征地、举债、注水——**这些是约束条件下的"解"，不是道德缺陷**。

**判据**：能事前预测行为方向；能解释同一县内富乡镇与穷乡镇的差异；能解释政策一变行为随之变。

**失效**：财政宽裕且边际归属清晰；强政治动员压过财政逻辑；收入数据严重失真；单一强人偏好主导。

### 框架 B：「土地—金融—城市化」闭环诊断
确认垄断结构（征地权与出让权在地方）→ 算三笔账 → 找载体（谁持证、谁借款）→ 看还款来源 → 判断闭环是否闭合（闭合则自我加速，断裂则风险显性化）。

### 框架 C：「项目制」运作还原
设专项 → 跑项目 → 配资金 → 批复 → 执行 → 验收留痕。逐环节问：谁受益、谁增加工作量、谁被绕开。

### 框架 D：「经营城市」诊断
认增长联盟 → 看收入依赖 → 看支出偏向 → 看定价策略（交叉补贴）→ 看风险转嫁。

### 框架 E：事权归属判定
外部性 → 规模经济 → 信息复杂性 → 激励相容。四问过后给出"该由哪一级办、该垂直还是属地"。

## 八、常见误解纠正

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 分税制把地方的钱拿走了，所以基层穷 | 总量上转移支付基本补足了缺口，问题不在总量 | 问题在**结构与分配**：人均转移支付地区差异、专项占比过高、县级截留统筹 |
| 土地财政就是卖地赚钱 | 全国口径下土地出让支出常与收入相当，纯卖地常不赚钱 | 真正收益在**土地相关税收 + 抵押杠杆**；出让金是撬动信贷的信用凭证 |
| 地方政府是市场的对立面 | 政府深度参与市场建设，以合约方式与市场嵌合 | 政府是市场的**共同生产者**；政企关系是一组权责合约 |
| 地方官只唯 GDP | 晋升概率极低，多数公务员更在意收入与福利 | 激励是**多目标、分层**的：主官看政绩，普通公务员看财政状况 |
| 农民负担重是基层干部贪 | 收费是为填补体制性收支缺口，名目多由上级文件"合法化" | 负担是**财政缺口向最弱端的转嫁**；贪腐是叠加因素，不是主因 |
| 取消农业税基层就轻松了 | 收入来源断了，事权还在 | 从"汲取型"转为"悬浮型"：不收钱，也不办事 |
| 房价是炒出来的 | 投机是加速器，不是发动机 | 供给端的**指标管制与供地结构**决定长期价格中枢 |
| 城投债是市场失灵 | 市场认为有隐性担保，低风险高收益，定价是"理性"的 | 这是**政府信用被市场化定价**的结果 |
| 政府公司化就是腐败 | 公司化是组织形态（目标、动员、考核），腐败是另一条机制 | 公司化解释**效率与偏执**；腐败解释**租金分配** |

## 九、使用边界

1. **数字必须带年份与口径**。财政数据变动快，量级可讲，精确值要提示"以最新统计为准"。
2. **不预测房价、不预测地方债务风险爆发时点**。这类预测涉及宏观政策与市场预期，超出社会学解释能力。
3. **区分"机制"与"评价"**。"这套机制导致基层负债"是机制判断；"这套机制应当废除"是价值判断，交付时要分开。
4. **警惕单因解释**。财政能解释很多，但解释不了全部（文化、人事、偶然事件都在起作用）。讲完财政，补一句"这只是其中一条线"。
