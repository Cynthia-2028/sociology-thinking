# 11 城乡二元与乡土社会

这一份回答一类问题：**为什么户籍改革多年城乡差别仍在？为什么城市化常是"地先到、人后到"？为什么农民看起来"保守"？**

---

## 一、城乡二元：五列制度清单

城乡二元不是收入差距，是**按户口划身份、据此分配资源与机会的制度体系**。它由五项制度层层叠加而成，每项拆三问：**谁发证、谁付钱、退出成本多高**。

| 制度 | 管什么 | 缺了它会怎样 |
|---|---|---|
| **户籍** | 身份登记，绑定粮油、住房、就业、教育 | 办不了许多基本手续；迁移需准入证明 |
| **土地** | 集体所有、承包权与经营权、征地制度、指标管理 | 财产无法变现、无法随人流动 |
| **粮食与补贴** | 统购统销的历史遗产、直补与保护价 | 早期是"人不能走"的直接原因 |
| **就业** | 招工身份、社保参保资格 | 同一岗位两种待遇 |
| **公共服务** | 教育、医疗、住房的属地绑定 | 人在城、资格在乡 |

**关键判断：这五项不是并列，是锁死的。**
> 粮食紧张 → 劝止进城 → 劝而不止 → 升级为户籍限制 → 人跑不了 → 低价征粮才可行

单拆一环，其余会把它拉回去。这就是"户籍改革多年、差别仍在"的机制解释。

**它是"人造"还是"自然"？** 找行为突变点：同一批人、同一块地，规则一改，吃饭问题几年解决。规则变了，人的能力没变——这是最有力的证据。

**拆除顺序**：先拆代价最小、松动耦合最多的一项。**入口在"允许人走"，不在"给钱"。**

**失效条件**：市场化私人替代品出现时（城中村租房、民办学校、跨省结算、居住证积分），约束被"绕过"而非"拆除"。此时应改问："绕道的价格是多少、谁付得起？"

## 二、人—地—钱错位：为什么新区总比人先到

**三项分别测流动自由度**：
- 人：落户门槛（最难动）；
- 地：指标与审批（较易动）；
- 钱：出让金归当期、债务推给未来（最易动）。

**结果**：地能"飞"到高价处（指标落地到近城），人不能。于是复垦的村留下老人，指标在近城变成高价净地。

**凡"地先到人后到"之处，三样同时出现**：房价先涨、入住率低、原住民留在原地。

**判据**：能事先指出某新区会空、某县城房价会先涨后滞，而非事后归因于"规划失误"。

**失效条件**：人口净流出、指标失去买家（收缩型城市），"地贵"前提消失，框架退化为财政问题。

## 三、农民算账模型：收益 / 负担 / 风险 / 退路

**这个模型专门用来破"农民保守""不愿改种""宁可打工"这类判断。**

| 栏 | 算什么 | 最容易漏的 |
|---|---|---|
| **收益** | 按亩、按工日折算，不按模糊的"年收入" | 新作物前几年零收益 |
| **负担** | 税、提留、统筹、两工折款、人头杂费、人情礼 | 报表只算前两项，隐性负担全漏 |
| **风险** | 价格（一多种就跌）、天灾、病、罚款、政策变 | 补偿标准逐年提高，早征的吃亏 |
| **退路** | 口粮田够不够、宅基地在不在、能否借到钱、城里待不下去能否回 | 退路是决策的锚 |

**核心结论**：农户不在"最大收益"处决策，在**"不跌破退路"**处决策。
> 这就是为什么只有拿到稳定非农收入的人才敢把全部承包地改种经济作物。早期调查里，一户全年结余只有几百元——容错空间就这么点，一次失败就跌破口粮线。

**判据**：能事先算出他为什么不改种、为什么不搬迁、为什么宁愿去工地。

**失效条件**：非农收入占七成以上时，重心移到"城里那份工稳不稳"，应改用"就业—社保"账。

## 四、权利安排决定收入分配（讲"征地"最有力的一节）

**同一块地，补偿能差出几十倍。差额不来自努力，来自"允许不允许交易"。**

把权利束拆开：**所有权、使用权、转让权、收益权**。
- 集体土地可自用、可自建，但不得向集体以外转让；
- 要转，只能先被征为国有。

**三种价格**：
1. **征地价**：原用途年均收益 × 倍数（曾由二十倍改为三十倍），无议价空间；
2. **指标价**：在试点额度内由竞争形成（如"增减挂钩"）；
3. **落地价**：由市场竞价形成。

**关键洞察**：**"一点点选择权"就值几十倍差价**。征地不可拒绝，挂钩可参加可不参加；就这一点自愿，补偿从每亩数万元升到二三十万元，再升到落地后数百万元。反推：想改变分配，先改权利；只喊"提高补偿标准"，标准仍在原框架内。

**判据**：能解释差额来自"允许不允许交易"，而非"谁更努力"。

**失效条件**：交易完全禁止、连"不参加"都没有时（纯征地），框架退化为"强制—补偿"，只能谈程序与公平。

## 五、确权、流转与市民化

**确权（rights confirmation）**：把模糊的集体权利边界丈量、登记、颁证到户。
- 它**不是私有化**，是划清边界，让交易成为可能。
- 没有证，抵押、流转、领补贴都办不了。
- 难点：成员与户数随生老病死、婚丧嫁娶变化，"长久不变"落不了地。

**土地流转**：承包权（成员资格）与经营权（耕作与处置）分离，经营权可转包。
- 转包条件常是"代缴税费 + 定量实物"；
- 风险：转入方跑路、地力下降、原承包户失去退路。

**市民化**：从"常住"到"落户"的资格转换，涉及社保、教育、住房的**可携带性**。
- 一代是"不敢落"（怕丢退路）；
- 二代是"落不下"（门槛与资格不接续）；
- 把社保、教育、住房从"地点"上解绑，比发户口更有效。

**空心村**：人走了、房没走、地不能动——**流动不同步**。
- 不是"农村没救了"，是制度锁定；
- 松开地的流动、补上服务，可转为低密度宜居。

## 六、乡土社会的秩序：三套旧机制仍在运行

| 机制 | 一句话 | 今天还在哪里起作用 |
|---|---|---|
| **差序格局** | 以己为中心，按亲疏远近推出去的关系结构 | 村里办事找谁、纠纷先找谁说和、资源怎么分 |
| **礼治** | 靠传统与教化维持的规范秩序，不是靠权力机构 | "无讼"观念：打官司被视为丢脸 |
| **教化权力** | 发生于世代继替中的第三种权力，非横暴也非同意 | 长辈对晚辈、老手对新手的人身示范 |

**三个必须说清的判断**：
1. **差序格局不是自私**。公私是相对的：为家牺牲族时，家就是公。缺的不是私德，是超越小团体的"团体"。
2. **"善分不善合"**：能分到家庭这一层，却难在家庭之上自建合作组织，于是公共品长期供给不足（修渠、打井、护路）。
3. **传统不是断裂，是载体更换**：断的是科举、宗族、乡绅，续的是情理、面子、关系。

## 七、田野怎么进入（做调查或写深度报道都用得上）

1. **双轨入场**：正式渠道（介绍信、许可）应酬多，"陪同"本身破坏现场；非正式渠道（亲友、同乡、师门）能直达现场。实操是"公私兼顾"：带正式身份，走私人关系。
2. **分层选人**：管账的（有数）→ 管全局的（有立场）→ 普通农户（有账、有怨气）→ 中间层（有苦衷、有比较）。四类说法互相校验。
3. **问"数"不问"看法"**：别问"负担重不重"，问"去年交了多少、分几项、折多少钱"。
4. **追问口径**：同一个村常有三套人口数字（管税费的、管计生的、实际住着的）。差额就是制度的缝隙。
5. **把听不懂的词当入口**：土话、行话、顺口溜是理解当地规则最快的门；听不懂就承认，请人从头讲。
6. **交叉验证三条线**：报表（给上面看的）、账本（实际收的）、闲谈（真实感受）。不一致时不要调和，把差额记下来。

**判据**：能说出这个村里哪个数字是做给上面看的、哪一笔是实际收的，并解释差额从哪来。

**失效条件**：涉及敏感事项时，陪同在场就无法取证；只能换时间、地点、介绍人，或承认"此处不可知"。

## 八、五个可操作框架（速查）

**A 城乡二元制度清单**：列五项 → 找龙头（户籍）→ 找耦合（五项如何锁死）→ 判"人造"还是"自然"（找行为突变点）→ 排拆除顺序。

**B 人—地—钱错位诊断**：测三项流动自由度 → 排序 → 看后果（地先到人后到的三个症状）→ 预测（房价先涨、入住率低、原住民留在原地）。

**C 农民算账模型**：收益（按亩按工日）→ 负担（含隐性）→ 风险（价格/天灾/病/政策）→ 退路（口粮、宅基地、借贷、回流）→ 定位决策点（不跌破退路）→ 复核。

**D 权利安排—收入分配分析**：拆权利束（所有/使用/转让/收益）→ 找三种价格（征地/指标/落地）→ 算分配比例 → 找"一点点选择权"的差价 → 反推改革入口。

**E 田野进入六步**：双轨入场 → 分层选人 → 问数不问看法 → 追口径 → 抓土话 → 三线交叉验证。

## 九、常见误解纠正

| 常见说法 | 为什么错（或只对一半） | 更准确的说法 |
|---|---|---|
| 农民保守，不愿冒险 | 不是不愿冒险，是风险承受力不同——全年结余只够一次失败 | 有稳定非农收入托底的人才敢改种；保守是"无退路"条件下的理性 |
| 农村落后是因为人不行 | 同一批人换个规则行为立刻变 | 差别在制度、基础设施、市场规模与训练机会 |
| 城市化就是让农民进城买房 | 把"人进城"缩成"买房"，把"地进城"隐掉了 | 真实顺序常是地先到、人后到；只让人买房不给资格，是把成本留给个人 |
| 农民负担重是基层干部坏 | 干部确有贪占，但主因是财政结构：机构要运转、没有企业税收就得向农民要 | 负担是"机构—财政—考核"链条的产出，换人有效但有限 |
| 土地是农民的，征地给够钱就行 | 关键不在钱多少，在允许不允许交易 | 先改权利安排，补偿标准才有意义 |
| 人情就是腐败，应当清除 | 人情是缺少正式保险与法律时的替代性互惠机制 | 区分"人情作为互惠"与"人情侵入公权" |
| 确权就是把地分给农民 | 确权是丈量、登记、颁证，不改变所有权归属 | 确权解决"边界不清导致无法交易" |
| 空心村说明农村没救了 | 人走了、房没走、地不能动，是制度锁定 | 空心是"流动不同步"的症状 |
| 农民工不落户是不想落户 | 一代不敢落，二代落不下 | 把社保、教育、住房从"地点"解绑 |
| 只要放开土地市场就解决了 | 放开能提高配置效率，也会带来资本下乡、指标炒作、弱质农户失地 | 放开须与确权、规划、社会保障同步 |

## 十、使用边界

1. **数字要带年份与口径**。农村收入、征地补偿标准变动快，讲量级可以，讲精确值要提示"以最新规定为准"。
2. **不代替法律与政策咨询**。涉及宅基地继承、征地补偿、土地流转合同的具体问题，只讲机制与常见坑，明确建议咨询当地主管部门或法律专业渠道。
3. **不浪漫化乡村，也不妖魔化乡村**。"乡土温情"与"熟人压力"是同一套机制的两面，两边都要写。
4. **地域差异极大**。沿海与内陆、城郊与远乡、平原与山区，同一机制的表现差别很大；下判断时要说清"在什么类型的村庄"。
